## 摘要
我们研究分布式拜占庭容错的演员-评论家多智能体强化学习（AC-MARL），其中智能体通过局部交互共同学习策略。现有方法仅能保证智能体参数收敛到无攻击极限点的一个邻域内，导致性能下降。我们提出完全容错AC-MARL（FRAC-MARL），这是一种去中心化方法，每个智能体利用两跳消息中的冗余来识别可靠消息。在价值和团队奖励函数的线性参数化以及拜占庭边缘攻击（对抗行为仅限于通信层）的条件下，我们证明在时变通信图上，智能体的参数几乎必然收敛到与无攻击情况下相同的极限点。我们为所提方法的收敛引入了一个新的拓扑条件，提出了一种构建此类网络的系统方法，并证明该条件可在多项式时间内验证。最后，我们在协作式多机器人编队控制任务上演示了我们的方法。

## Abstract
We study distributed Byzantine-resilient actor-critic multi-agent reinforcement learning (AC-MARL), where agents collectively learn policies through local interactions. Existing methods guarantee convergence of the agents' parameters only to a neighborhood of the attack-free limit points, resulting in degraded performance. We propose Fully Resilient AC-MARL (FRAC-MARL), a decentralized method in which each agent leverages redundancy in two-hop messages to identify reliable messages. Under linear parameterizations of the value and team-reward functions and Byzantine edge attacks, where adversarial behavior is confined to the communication layer, we prove that agents' parameters converge almost surely to the same limit points as in the attack-free case over time-varying communication graphs. We introduce a novel topological condition for the convergence of our method, present a systematic method to construct such networks, and prove that this condition can be verified in polynomial time. Finally, we demonstrate our method on cooperative multi-robot formation control tasks.

- **研究背景**：分布式协作多智能体强化学习（MARL）中，智能体通过邻居间的信息共享来优化全局目标。然而，这类系统极易受到拜占庭攻击（Byzantine attacks），即攻击者可任意篡改或丢弃通信消息。
- **核心问题**：现有的拜占庭容错 MARL 方法（如基于修剪均值或投影的方法）存在根本性局限——它们只能保证智能体参数收敛到无攻击最优解的一个“邻域”内，而非精确收敛。这导致最终学习到的策略性能显著下降。
- **研究动机**：本文旨在设计一种“完全弹性”的算法，使得在通信层遭受拜占庭边缘攻击的情况下，智能体的学习结果能完全等同于无攻击时的情形，从而消除性能退化。

### 2. 论文提出的方法论

- **核心思想**：利用两跳通信带来的消息冗余来识别并过滤被篡改的信息。每个智能体不仅接收邻居的消息，还接收邻居转发的、来自两跳邻居的消息。由于攻击者只能破坏有限数量的边（F-total Byzantine edge attack），同一原始消息会通过多条独立路径到达，形成冗余副本。
- **关键技术细节**：
    - **FRAC-MARL 算法流程**：
        1.  **本地更新**：每个智能体执行标准的演员-评论家更新，得到临时的价值函数参数 `ṽ` 和奖励函数参数 `λ̃`。
        2.  **两跳通信**：智能体将包含 `(ṽ, λ̃, agent_id)` 的消息发送给一跳邻居；一跳邻居再将收到的消息转发给它们自己的邻居。
        3.  **冗余过滤与共识**：对于每个声称来自智能体 `k` 的消息，接收方 `i` 会收集所有通过不同中继节点传来的副本。然后执行一个“众数投票”机制：如果某个参数元组出现的次数超过阈值 `τ = r - F`（其中 `r` 是拓扑冗余度参数），则认为该消息是可靠的。最后，仅使用这些可靠消息进行加权平均来更新自身参数。
    - **拓扑条件——(r, r')-冗余性**：
        -   **定义**：一个图是 (r, r')-冗余的，如果其 r-2-hop图是连通的，且任何不直接相连的节点对共享的邻居数不超过 r'。
        -   **作用**：该条件保证了在最多 F 条边被攻击时，(i) 可靠节点间有足够的冗余路径 (`≥ r`)；(ii) 不可靠节点无法伪造出足够的冗余 (`≤ r' < τ`)；(iii) FRAC-MARL过滤后形成的“诱导通信图”是对称且连通的。

        -   **引理2 &amp;3**:证明在满足 (r, r −2F −1)-冗余性且 r >2F的条件下，FRAC-MARL能完全过滤掉所有被篡改的消息，并且诱导出的通信图等同于无攻击时的连通、无向图。
