## 摘要
大型语言模型（LLM）智能体越来越多地通过外部工具执行长时程工作流，使得不可信输出能够影响后续动作并超出用户授权范围。现有防御措施隔离注入内容，或通过预定义计划和静态策略约束执行，但这些方法在动态工作流下脆弱，且难以在可扩展的工具生态系统中良好扩展。在本文中，我们提出了 ActGov，一个运行时执行框架，在每个 LLM 提出的工具动作产生外部影响之前对其进行验证。ActGov-Policy 组件建立在授权、动作、运行时上下文和安全约束的统一语义模型之上，从工具规范、良性任务和观察到的失败轨迹中迭代构建策略集，每次更新都通过基于 SMT 的反例检查进行验证。在运行时，ActGov-Runtime 将每个工具调用抽象为有限策略记录，仅当它保持在任务范围的授权边界内并满足所有适用策略时才允许执行。这种逐动作执行在长时程、动态分支的工作流中始终保持授权。我们在 AgentDojo 和 AgentDyn 基准上，跨多种模型和攻击配置评估了 ActGov。结果表明，ActGov 在保持任务效用的同时，持续降低了间接提示注入攻击的成功率，显著优于现有防御。这些结果表明，ActGov 能够在动态智能体执行过程中实施细粒度授权，而无需依赖底层 LLM 正确识别恶意指令。

## Abstract
Large language model (LLM) agents increasingly execute long-horizon workflows through external tools, allowing untrusted outputs to influence subsequent actions and exceed user authorization. Existing defenses isolate injected content or constrain execution with predefined plans and static policies, but these approaches are brittle under dynamic workflows and scale poorly across extensible tool ecosystems.   In this work, we present ActGov, a runtime enforcement framework that validates each LLM-proposed tool action before it causes external effects. Built on a unified semantic model of authorization, actions, runtime context, and security constraints, the ActGov-Policy component iteratively constructs a policy set from tool specifications, benign tasks, and observed failure traces, with each update verified through SMT-based counterexample checking. At runtime, ActGov-Runtime abstracts each tool call into finite policy records and permits it only if it remains within the task-scoped authorization boundary and satisfies all applicable policies. This per-action enforcement preserves authorization throughout long-horizon, dynamically branching workflows.   We evaluate ActGov on the AgentDojo and AgentDyn benchmarks across multiple models and attack configurations. It shows that ActGov consistently reduces the success rate of indirect prompt-injection attacks while preserving task utility, significantly outperforming existing defenses. These results demonstrate that ActGov can enforce fine-grained authorization over dynamic agent executions without relying on the underlying LLM to correctly identify malicious instructions.

## 1. 论文的核心问题与整体含义

- **研究动机**：LLM 智能体正从文本生成器演化为能自主调用外部工具、执行多步骤长时程工作流的系统。模型输出可能直接触发高影响操作（如修改、删除、授权），核心安全风险是**间接提示注入（IPI）**：不可信外部内容被误解为用户意图，导致智能体执行越权动作。
- **现有防御的局限**：
  - 缺乏统一的语义框架来表示智能体动作及其与授权、数据来源之间的关系；
  - 对长时程、动态分支工作流的鲁棒性不足，预定义计划或静态参数检查表要么过度限制合法自适应行为，要么在偏离预设假设时失效；
  - 策略构建在工具生态扩展时难以规模化，自动化生成策略缺乏对遗漏、冲突或非预期权限的严格检测。
- **整体含义**：提出 **ActGov**，一个形式化验证的运行时授权框架，将智能体的**动作提议**与**执行授权**分离，在每次工具调用产生外部影响前进行逐动作验证，不依赖底层 LLM 识别恶意指令。

## 2. 方法论：核心思想与关键技术细节

- **核心思想**：将非结构化运行时上下文映射到**有限二维记录空间 R**，在该空间上定义、验证并强制执行安全策略。LLM 仅用于有界的信息提取（语义解析），授权决策由确定性策略解释器完成。
- **形式化模型**：智能体受 ActGov 保护后建模为有限状态机：
  \[
  M = (H, C, R, P, V, T)
  \]
  其中 \(H\) 为执行历史状态空间，\(C\) 为候选工具调用空间，\(R\) 为有限记录空间，\(P\) 为策略集，\(V: R \times P \to \{\text{allow}, \text{deny}\}\) 为确定性评估函数，\(T\) 为状态转移函数。外部工具仅在 \(v_i = \text{allow}\) 时执行。
- **正交二维记录模式**：
  - **形成层级**：
    - L1 确定性：直接从显式系统状态计算，不需自然语言处理；
    - L2 有界语义：需要语义理解，但 LLM 仅作为解析器，输出映射到预定义有限值域；
    - L3 组合：由 L1/L2 值通过布尔逻辑（AND/OR/NOT）组合得到。
  - **语义范围**：动作、权限、参数、历史、绑定、外部、领域，共七个域。
- **分层授权策略** \(P = P_{TP} \cup P_{HI} \cup P_{PO}\)：
  - **任务权限（Task-Permission）**：将可信用户任务绑定到最小所需工具和资源，生成基准授权边界 `perm`；
  - **硬不变量（Hard-Invariant）**：编码全局安全属性，例如禁止源自不可信注入内容的外发网络动作；
  - **程序性义务（Procedural-Obligation）**：处理超出智能体自主处理权限的条件，要求满足特定前置条件或上下文约束后才允许执行。
- **验证门控演化**：在 ActGov-Policy 阶段离线进行。每次策略更新由 Z3 SMT 求解器检查，搜索是否存在于有限记录域内满足策略语义但违反安全断言 \(A_{sec}\) 的赋值：
  \[
  \exists r, v. \text{Domain}_R(r) \land P_{sem}(r, v) \land \neg A_{sec}(r, v)
  \]
  - **SAT**：暴露缺口或冲突，触发策略细化；
  - **UNSAT**：保证策略集合不引入矛盾且保持安全不变量。
  - 全部验证在部署前完成，运行时不调用求解器。
- **ActGov-Runtime**：拦截候选工具调用，依据 \(P_{TP}\) 解析 `perm`，并通过抽象函数 \(\alpha_R(\tau, perm, H_i, c_i)\) 将当前上下文填充为记录集 \(r_i\)，再对策略集进行确定性求值。动作仅当处于 `perm` 边界内且不违反任何安全策略时才被允许。

## 7. 优点

- **统一语义抽象**：正交二维记录空间将授权、动作、来源、绑定等异构因素映射为有限、可验证的离散值，避免了现有方法各自为政的表示缺陷。
- **离线验证 + 运行时确定性执行**：SMT 验证在部署前完成，运行时不引入求解器延迟，兼顾形式保证与低时延。
- **LLM 角色受限**：LLM 仅作为有界语义解析器，不参与最终安全决策，显著压缩了推理幻觉和注入攻击的影响面。
- **分层策略结构**：任务权限、硬不变量、程序性义务分别处理基线授权、全局安全属性和条件性约束，设计清晰。
- **动态工作流适用性**：代理可自由适应运行时观察结果，同时每次工具调用仍受确定性策略约束，解决了静态计划防御对动态分支工作流过度保守的问题。
- **实验设计较全面**：跨两个基准、四个模型后端、多个防御基线，并设置消融与跨域迁移实验，验证维度较充分。

## 8. 不足与局限

- **跨域泛化能力弱**：策略在未见环境或工具上会退化为极度保守的拒绝行为，导致效用显著下降。开放式世界的策略泛化仍是未解决问题。
- **依赖训练覆盖**：策略质量依赖于良性任务与攻击样本的广度和代表性。覆盖不全时安全性尚可，但效用受损。
- **算力资源未披露**：无法评估实际训练/推理成本与部署可行性。
- **主实验非对称比较**：策略生成使用更强模型（GPT-5.5）并引入 HITL，可能高估自动化条件下的表现；自动消融中效用明显下降。

等字段的提取错误仍可能导致合法动作被误拒或非法动作被放行，且提取器本身在运行时仍暴露于间接提示注入的欺骗风险；尽管其输出值域有限，攻击者仍可能通过构造上下文诱导错误记录，从而间接影响策略评估结果。因此，ActGov 的安全保证在很大程度上建立在记录提取的语义可靠性之上，而这一前置条件在论文中尚未被独立验证或提供形式化误差上界。
