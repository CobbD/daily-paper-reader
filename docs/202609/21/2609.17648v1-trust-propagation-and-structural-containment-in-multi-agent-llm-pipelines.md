## 摘要
多智能体大语言模型系统越来越多地自动执行涉及不同权限级别智能体的任务，由此产生一种安全风险：被攻陷的低权限智能体可能影响高权限智能体并触发未授权操作。我们研究了一个由 Supervisor、Researcher、Validator 和 Executor 四个智能体组成的 LangGraph 流水线中的攻击传播。我们评估了共享内存投毒，以及通过在检索到的文档中嵌入伪造批准而实施的间接提示注入。我们将 Validator 的判断与一个独立授权层进行比较，该授权层使用任务绑定的签名令牌和单独验证的策略预言机。我们的贡献包括：对攻击传播的实证研究、对授权边界的组件级消融分析，以及判断绕过率（JBR），该指标衡量受攻击智能体处的失陷情况，而非最终动作处。在三个随机种子和 60 个带标注任务中，内存投毒在每次未设防试验中都到达执行阶段。启用授权后，它达到 100% 的 JBR，但不安全动作率为 0%，表明 Validator 可能仍被攻陷，而执行可被遏制。针对拥有签名密钥的攻击者，策略预言机提供了所观察到的遏制效果，而独立制定的最小权限策略仍能保持这一结果。一个 Observer 层将智能体劫持的误报率从 49% 降低到 7%，且不削弱执行级安全性。这些结果表明，即使上游 LLM 判断失败，结构化授权也能遏制被攻陷智能体的行为。

## Abstract
Multi-agent LLM systems increasingly automate tasks involving agents with different levels of privilege, creating a security risk in which a compromised low-privilege agent can influence a higher-privilege agent and trigger an unauthorized action. We study attack propagation in a four-agent LangGraph pipeline comprising a Supervisor, Researcher, Validator, and Executor. We evaluate shared-memory poisoning and indirect prompt injection through a forged approval embedded in a retrieved document. We compare the Validator's judgment with an independent authorization layer using task-bound signed tokens and a separately verified policy oracle. Our contribution is an empirical study of attack propagation, a component-level ablation of the authorization boundary, and the Judgment Bypass Rate (JBR), which measures compromise at the attacked agent rather than at the final action. Across three seeds and 60 labeled tasks, memory poisoning reaches execution in every undefended trial. With authorization enabled, it achieves 100% JBR but 0% Unsafe Action Rate, showing that the Validator can remain compromised while execution is contained. Against an attacker possessing the signing secret, the policy oracle provides the observed containment, while an independently authored least privilege policy preserves this result. An Observer layer reduces the false-positive rate for agent hijacking from 49% to 7% without weakening execution-level security. These results show that structural authorization can contain compromised agent behavior even when upstream LLM judgment fails.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在多智能体 LLM 系统中，低权限代理被攻陷后，可能通过信任传播影响高权限代理并触发未授权操作，即“混淆代理（confused deputy）”问题。
- **背景与动机**：多智能体系统常将检索、审查、执行等职责分离，低权限代理负责检索与摘要，高权限代理执行敏感操作。传统研究多关注“LLM 是否被骗”，而较少评估“失陷是否最终到达真实系统动作”。本文聚焦于下游安全边界，验证结构化授权是否能在上游 LLM 判断失败时仍遏制失陷行为。
- **整体含义**：将“LLM 判断”与“授权执行”解耦，即使 Validator 等上游代理被绕过后，独立授权层仍能阻止未授权动作，从而提升多智能体系统的执行级安全性。

## 2. 论文提出的方法论

- **系统架构**：实现四代理 LangGraph 流水线：
  - **Supervisor**：确定性路由器，不调用 LLM；
  - **Researcher**：低权限、只读检索；
  - **Validator**：中权限、审批门；
  - **Executor**：高权限、执行真实动作。
- **结构化授权边界**：
  - 使用 **HMAC 签名、任务绑定、单次使用令牌**；
  - 独立验证的**策略预言机（policy oracle）**，在执行前重新推导权限；
  - 仅当令牌验证和策略检查同时通过时，动作才到达 SQLite 邮箱存储层。
- **攻击模型**：
  - **共享内存投毒（memory poisoning）**：替换 Validator 为被攻陷例程，伪造批准；若拥有签名密钥，则生成有效授权令牌。
  - **智能体劫持（agent hijacking）**：在检索文档中注入伪造的“已批准、置信度、来源声明”，间接提示注入 Validator。
- **关键指标**：
  - **Unsafe Action Rate (UAR)**：金标不安全任务中实际执行的比例；
  - **Legitimate Task Completion (LTC)**：金标安全任务被允许完成的比例；
  - **False Positive Rate (FPR)**：安全任务被误阻断的比例；
  - **Judgment Bypass Rate (JBR)**：受攻击代理的审查/判断被绕过或跳过的比例，区分“审查失效”与“最终未授权动作”。
- **Observer 层**：位于 Researcher 与 Validator 之间，仅检测并移除“已审核、已验证、已预批准”等显式注入声明，不判断任务安全性，也不能批准或阻止动作；作为效用保护组件而非安全边界。

## 6. 论文的主要结论与发现

- **内存投毒**：无防御 T0 下 UAR=100%，攻击在所有未设防试验中到达执行；启用 T1 后 UAR=0%，但 JBR=100%，说明 Validator 仍被绕过，执行被独立授权层遏制。
- **智能体劫持**：无论 T0 还是 T1，UAR 均为 0%，但 Validator 对合法任务也频繁误拒；T0 FPR=59.3%，T1 FPR=49.1%，显示结构授权不解决 Validator 误报问题。
- **授权消融**：当攻击者持有签名密钥时，仅令牌条件与 T0 一样 UAR=100%；仅策略预言机条件与 T1 一样 UAR=0%。因此，**在密钥泄露场景下，真正承担遏制作用的是策略预言机，而非签名令牌**。签名令牌仍可用于防伪、绑定任务与防重放，但不直接决定权限。
- **独立策略评估**：UAR 在两种策略和两种攻击下均保持 0%；内存投毒下 F1=1.00，劫持下独立策略与 corpus policy 的 FPR 接近（46.3% vs 49.1%），说明遏制不是“用评估标签推导策略”的伪结果。
- **Observer 层**：将劫持攻击的 FPR 从 49.1% 降至 7.4%，LTC 从 50.9% 升至 92.6%，F1 从 0.74 升至 0.95，UAR 仍为 0%；JBR 从 0% 升至 4.2%，但执行级安全不变。
- **总体结论**：结构化授权可以在上游 LLM 判断失败时有效遏制被攻陷代理的行为，证明“上游失陷”并不必然导致“最终未授权动作”。
