## 摘要
检索增强生成（RAG）系统通过外部知识增强大语言模型（LLMs），但已被证明容易受到语料库投毒攻击。现有针对 RAG 的投毒攻击主要集中在单点显式注入，即恶意载荷完全封装在单个文档中。因此，近期的缓解机制已发展为能够有效识别和削弱这些威胁。本文首先验证现有缓解机制对一类新型威胁——间接逻辑诱导——的不足。受此观察启发，我们提出 InceptionRAG，一种颠覆标准攻击范式的隐蔽攻击机制。InceptionRAG 不注入显式恶意载荷，而是将其拆分为一系列休眠段落。这些段落单独检查时看似无害，能够绕过现有缓解机制；然而，当它们被一起检索到时，会触发 LLM 通过多跳推理自行推导出目标错误信息。为进一步提升 InceptionRAG 在黑盒环境中的适用性，我们提出零阶后缀优化（ZOSO）以自动生成权威后缀。在三个数据集和三个 LLM 上的广泛评估表明，即使在严格对抗约束下，InceptionRAG 的攻击成功率仍超过 80%。特别是，InceptionRAG 展现出优越的规避能力，能有效绕过缓解传统单文档注入的既有防御。我们的发现揭示了一个令人担忧的悖论：LLM 的推理能力越强，其面对基于推理的投毒攻击时越脆弱。为减轻潜在滥用，我们提出基于文档隔离的防御 HODOR，以解耦对抗性逻辑依赖。

## Abstract
Retrieval-augmented generation (RAG) systems enhance large language models (LLMs) with external knowledge but have been demonstrated to be vulnerable to corpus poisoning. Existing poisoning attacks against RAG largely focus on single-point explicit injection, where the malicious payload is fully encapsulated within a single document. Consequently, recent mitigation mechanisms have evolved to identify and diminish these threats effectively. In this paper, we first verify that existing mitigation mechanisms are insufficient for a new class of threats: indirect logic induction. Motivated by this observation, we introduce InceptionRAG, a stealthy attack mechanism that subverts the standard attack paradigm. Instead of injecting explicit malicious payloads, InceptionRAG fragments it into a chain of dormant passages. These passages appear harmless and can bypass existing mitigation mechanisms when examined separately. However, when retrieved together, they trigger LLMs to self-deduce target misinformation via multi-hop reasoning. To further improve the applicability of InceptionRAG in black-box settings, we propose zeroth-order suffix optimization (ZOSO) to automate the generation of authoritative suffixes. Extensive evaluations across three datasets and three LLMs demonstrate that InceptionRAG achieves an attack success rate exceeding 80% even under rigorous adversarial constraints. In particular, InceptionRAG shows superior evasion capabilities, effectively bypassing established defenses that mitigate traditional single-document injections. Our findings expose a concerning paradox: the stronger reasoning capabilities of LLMs increase their vulnerability to reasoning-based poisoning attacks. To mitigate potential misuse, we propose a document isolation-based defense, HODOR, which decouples adversarial logical dependencies.

## 1. 核心问题与整体含义

- **研究背景**：检索增强生成（RAG）通过引入外部知识库缓解大语言模型（LLM）的幻觉和知识过时问题，但外部语料的不可信引入了新的攻击面——语料投毒。
- **现有攻击的局限**：当前投毒攻击主要采用“单点显式注入”，即把恶意载荷完全放在单个文档中，直接、显式地将目标答案与查询关联。这类攻击会留下可检测的异常模式（如注意力方差异常、关键词密度过高、跨文档事实冲突等），因此可以被现有的基于单文档检查的防御机制有效过滤。
- **本文核心问题**：现有防御对“间接逻辑诱导”类新型威胁是否仍然有效？作者发现答案是否定的，并由此提出一种隐蔽攻击机制 **InceptionRAG**，将恶意信息分散到多个看似无害的文档，诱导 LLM 通过多跳推理自行合成虚假结论。
- **整体含义**：该工作揭示了一个令人担忧的悖论——LLM 的推理能力越强，就越容易受到基于推理的投毒攻击。其根本原因在于攻击者不再直接注入毒药，而是注入“逻辑链条”，使毒害在模型聚合上下文的推理过程中才出现。


## 2. 方法论

- **核心思想**：**“孤立休眠，聚合致毒”**。将目标错误答案拆分为多个逻辑片段，分别注入不同文档；每个文档单独看与查询无关，无法触发安全过滤；但被 RAG 同时检索后，LLM 会通过多跳推理自行推导出目标答案。

- **逻辑陷阱构建**：
  - 引入**代理实体** \(e_{\text{proxy}}\)，与目标实体 \(e_{\text{target}}\) 语义相似但不同。
  - **属性文档** \(d_{\text{attr}}\)：陈述代理实体具有目标答案值，例如“阿根廷赢得了 2016 年奥运会”，但不提及目标实体。
  - **桥文档** \(d_{\text{bridge}}\)：建立目标实体与代理实体在查询属性上的等价关系，例如“2016 年奥运会冠军与 2018 年世界杯冠军是同一国家”，但不显式给出答案。
  - 当两个文档同时出现在上下文时，LLM 会执行如下三段论推理：
    \[
    (e_{\text{target}} \equiv e_{\text{proxy}}) \land (\text{Value}(e_{\text{proxy}}) = a^*) \Rightarrow \text{Value}(e_{\text{target}}) = a^*
    \]
    从而“洗白”错误信息，因为它不是被检索语料直接提供的，而是在生成过程中被合成。

- **零阶后缀优化（ZOSO）**：
  - 为增强恶意逻辑在大量良性上下文中的影响力，在属性文档和桥文档后分别追加“权威后缀”（anchor suffix）和“桥接后缀”（bridge suffix），提升 LLM 对恶意片段的信任和逻辑替换倾向。
  - 由于候选后缀空间巨大、黑盒 API 调用昂贵，ZOSO 将离散后缀映射到连续嵌入空间，利用 **神经正切核（NTK）** 构建高斯过程代理模型，通过梯度上升估计最优后缀。避免了暴力搜索 \(O(M \times N)\) 的复杂度。
  - 具体流程：用代理 LLM 生成候选池 → K-means 选代表 → 在黄金集上评估奖励 → NTK-GP 建模 → 梯度更新嵌入 → 在候选池中选最近邻后缀继续评估。采用**两阶段交替优化**：先固定桥后缀优化 anchor，再固定 anchor 优化 bridge。

- **检索概率最大化**：
  - **关键令牌提取**：去除停用词，保留高语义密度核心词。
  - **双端注入**：在文档开头插入查询主体（Header），在文档末尾附加伪元数据标签（Footer），利用密集检索器的位置偏置，提高对抗文档被检索进 top-\(k\) 的概率，同时维持文本自然感。

- **全局后缀适应**：
  - **多态噪声注入**：在优化后缀外包裹随机十六进制 ID 和随机时间戳，使每个实例表面唯一，抵御基于正则/字符串匹配的检测，同时 LLM 仍能关注到不变的核心指令。
  - **级联测试时微调（CTTFT）**：当全局后缀失败时，按“全局探测 → 邻居 anchor 适应 → 邻居 bridge 适应”三级搜索，在最多 25 次查询内找到对当前查询更有效的后缀，大幅提升泛化性。

- **攻击目标形式化**：目标是最大化检索概率与生成概率的联合概率：
  \[
  \max_{P} \Pr(P \subseteq R(q, \mathcal{D})) \times \Pr(y = y_t \mid q, \Phi(C \cup P))
  \]
  其中 \(\Phi\) 表示防御过滤函数，\(P\) 为对抗文档集。

## 6. 主要结论与发现

- **高攻击有效性**：在严格约束（\(N=2\)、\(k=10\)）下，InceptionRAG 在无防御环境中于 Gemini-2.0-Flash 上取得 **NQ 88.0%、HotpotQA 90.3%、MS-MARCO 83.3%** 的 ASR，显著优于三种基线攻击（多数差距超过 10–50 个百分点）。
- **防御绕过能力强**：对 AVFilter、MIS、RAGForensics 等防御，ASR 和 BR 大幅领先基线；尤其对 AVFilter，在 NQ 上 ASR 高达 72.3%，BR 90.4%，而最强基线 ASR 仅 16.7%。
- **模型规模与脆弱性正相关**：从 7B 参数开源模型到大规模黑盒模型，ASR 随模型推理能力增强而上升；例如 Llama-2-7B 在 NQ 仅 46.0%，Gemini-Flash 达 88.0%。这印证了“推理能力越强，越易被基于推理的投毒攻击利用”的悖论。
- **组件有效性**：ZOSO 相比无后缀/随机后缀带来显著 ASR 提升（如 MS-MARCO 上 41.3% → 83.3%）；CTTFT 相比仅全局后缀也大幅提升（Gemini MS-MARCO 22.0% → 83.3%）。
- **检索鲁棒性**：在查询重写和跨检索器场景下，对抗文档通常能以接近 100% 的“2/2”命中率被检索，说明双端注入有效。
- **自适应防御 HODOR**：通过文档隔离和多数投票，能显著降低攻击 ASR，但也导致多跳问答等需要跨文档推理的良性任务性能明显下降。


## 7. 优点

- **范式创新**：首次系统研究“间接逻辑诱导”类隐蔽投毒，突破传统单点显式注入框架，揭示现有防御的结构性盲点。

## 8. 局限性与潜在问题

- **攻击条件依赖较强**：InceptionRAG 依赖目标答案可被单一属性文档承载、代理实体与目标实体在语义上足够接近、查询属性可被桥接等条件。对于多值答案、复杂生成任务或高度抽象查询，攻击构造难度会明显增加。
- **对统计类防御不够稳定**：在 HotpotQA + FilterRAG 场景下，ASR 降至 15.3%，说明当任务本身多跳结构与攻击叠加导致关键词密度等统计特征异常时，攻击仍可能被削弱；作者未对这类失败案例做进一步机制分析或改进。
- **防御评估范围有限**：HODOR 主要评估了对 ASR 的抑制和对多跳问答良性性能的影响，但对其他类型良性任务（如单跳问答、摘要生成）的性能损失、与其他防御机制的组合效果、以及面对自适应攻击变体时的鲁棒性讨论不足。
- **未涉及动态语料与多轮交互**：实验基于静态检索库，未考虑语料更新、多轮对话中上下文累积或检索缓存等现实场景对攻击成功率的影响。
- **伦理与滥用风险**：论文公开了高效的隐蔽投毒方法，虽然同时提出防御，但攻击细节可能被恶意利用，需要在披露与安全之间进一步权衡。

## 9. 总体评价与启示

- **学术贡献**：InceptionRAG 将 RAG 投毒从“单点显式注入”推进到“分布式逻辑诱导”范式，系统揭示了 LLM 多跳推理能力带来的新型安全脆弱性，为 RAG 安全研究开辟了新的方向。
- **现实意义**：该攻击在极低恶意文档占比（1:4）和黑盒条件下仍能取得高 ASR，且可绕过多种现有防御，表明当前防御体系存在结构性盲区，需要从“单文档检查”转向“跨文档逻辑一致性验证”。
- **防御方向**：HODOR 的文档隔离与多数投票思路虽然有效，但以牺牲多跳推理性能为代价，提示未来防御应更精细地区分“良性逻辑桥接”与“恶意逻辑诱导”，例如通过推理路径可视化、实体关系图谱校验或对代理实体替换的异常检测。
- **开放问题**：如何在不损害 LLM 多跳推理能力的前提下，设计轻量、可扩展的跨文档语义一致性过滤器，是后续工作的关键挑战。
