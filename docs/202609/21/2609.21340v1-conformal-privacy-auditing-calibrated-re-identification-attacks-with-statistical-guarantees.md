## 摘要
已发布文本的经验性身份泄露日益由攻击者驱动，这些攻击者结合大型语言模型（LLMs）与辅助知识将文档关联到个人。现有审计通常报告特定攻击流程的成功率，但缺乏有限样本统计保证；而训练时保护（如差分隐私）难以转化为针对单个自然语言文档的发布时决策。我们提出共形隐私审计（CPA），一个免分布的校准框架，为每份发布文档提供针对由LLM赋能的对手的重识别风险的统计证书。CPA输出候选身份的共形模糊集，在可交换性条件下保证以用户选择的置信度包含真实身份，并给出由集合大小导出的可解释泄露代理指标。CPA支持logit访问和仅采样型攻击者，从而在统一框架内审计开源模型和专有API模型。在多个发布基准和攻击者配置中，CPA实现了校准的覆盖率，并揭示了随着辅助知识、LLM增强和发布机制的变化，认证可识别性的显著变化，为跨攻击者配置、数据集和发布机制报告和比较发布时链接风险提供了基于统计的基础。

## Abstract
Empirical identity leakage from released text is increasingly driven by attackers that combine large language models (LLMs) with auxiliary knowledge to link documents to individuals. Existing audits typically report success rates for specific attack pipelines but lack finite-sample statistical guarantees, while training-time protections such as differential privacy are difficult to translate into release-time decisions for individual natural-language documents. We introduce Conformal Privacy Auditing(CPA), a distribution-free calibration framework that provides a statistical certificate of re-identification risk for each released document against LLM-empowered adversaries. CPA outputs a conformal ambiguity set of candidate identities that is guaranteed to contain the true identity with user-chosen confidence under exchangeability, together with an interpretable leakage proxy derived from set size. CPA supports both logit-access and sampling-only attackers, enabling audits of open-source models and proprietary API models in a unified framework. Across multiple release benchmarks and attacker configurations, CPA achieves calibrated coverage and reveals sharp shifts in certified identifiability as auxiliary knowledge, LLM augmentation, and release mechanisms vary, providing a statistically grounded basis for reporting and comparing release-time linkage risk across attacker configurations, datasets, and release mechanisms alike.

# 论文总结：Conformal Privacy Auditing（共形隐私审计）

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：随着大语言模型（LLM）的广泛应用，发布文本（如临床记录、法律文书、在线帖子）中的身份链接风险显著上升。攻击者可利用LLM从文本中提取线索，并结合辅助知识（如人口统计、公共注册信息）对个人进行重识别，即使文本经过脱敏或改写。
- **现有方法的不足**：
  - 差分隐私（DP）提供形式化最坏情况保证，但对自然语言文本而言过于保守，导致实用性大幅下降，且难以转化为单文档的发布时决策。
  - 经验性隐私审计（如重识别成功率）提供了实际泄漏证据，但**缺乏有限样本统计保证**，无法将测得的风险泛化到未见数据或更强的攻击者。
- **研究目标**：提出一个**免分布（distribution-free）的校准框架**，为每份发布文档提供针对特定攻击者配置的重识别风险统计证书，解决“发布时决策缺乏统计基础”的核心问题。

## 2. 论文提出的方法论

- **核心思想**：将重识别审计形式化为**构造共形模糊集（conformal ambiguity set）**。给定发布文档 x 和攻击者知识水平 w，CPA 输出候选身份集合 \(C_\alpha(x,w)\)，保证在可交换性下以 \(1-\alpha\) 置信度包含真实身份。集合大小 \( |C_\alpha(x,w)| \) 作为**可解释的泄漏代理**（leakage proxy），反映攻击者剩余的不确定性。
- **关键技术细节**：
  - **非一致性分数（APS mass score）**：采用自适应预测集（APS）风格的累积概率质量分数：
    \[
    s(x,y;w) = \sum_{j:\, p_A(\pi_j|x,w) \ge p_A(y|x,w)} p_A(\pi_j | x,w)
    \]
    该分数越小，表示攻击者将概率集中在真实身份上（链接风险越高）。
  - **Split Conformal 校准**：在留出校准集上计算非一致性分数，取第 \(\lceil (n+1)(1-\alpha)\rceil\) 个顺序统计量作为阈值 \(\hat{q}_\alpha\)，然后对测试文档构造模糊集：
    \[
    C_\alpha(x,w) = \{ y \in \mathcal{Y}(x,w) : s(x,y;w) \le \hat{q}_\alpha \}
    \]
  - **支持两类攻击接口**：
    - **logit 访问**：直接使用候选概率 \(p_A\) 计算分数。
    - **仅采样访问**：通过 \(m\) 次强制选择查询得到经验频率 \(\hat{p}_m\)，代入分数；适用于专有 API 模型。
  - **统计保证**：
    - **定理 5.2（有限样本有效性）**：在可交换性、闭世界假设（\(\rho(w)=0\)）下，\(\Pr(Y_{n+1}\in C_\alpha(X_{n+1},w)) \ge 1-\alpha\)。
    - **推论 5.3（开放世界扩展）**：若候选池漏检概率为 \(\rho(w)\)，则无条件覆盖下界为 \(1-(\rho(w)+\alpha)\)。
  - **泄漏代理**：\(L(x,w)=1/\max\{1,|C_\alpha(x,w)|\}\)，不是重识别概率，只是模糊集大小的单调变换。
- **算法流程**（Algorithm 1）：对校准集每个样本构建候选池，计算分数，排序取阈值；对测试样本构造候选池，计算分数，输出满足阈值条件的候选集合。

## 3. 实验设计

- **数据集与场景**：

  - **TextWash**：1,202 对原始/匿名描述，分为 famous、semi-famous、fictional 三类，用于模拟不同外部知识可用性。

  - **Blog Authorship Corpus**：大型作者身份链接场景，每个作者用 \(W \in {1,3,10}\) 篇留出帖子构建画像，控制辅助信息强度。
- **攻击者与知识水平**：
  - **检索攻击者（Retrieval-CPA）**：使用 TF-IDF 向量化和余弦相似度，构建候选画像排名，可通过 LLM 提取线索扩展查询（direct vs direct+clues）。

## 6. 论文的主要结论与发现

- **CPA 提供了校准的、威胁模型特定的证书**：经验覆盖率普遍接近目标 \(1-\alpha\)（如 0.95），验证了共形保证的有效性。
- **隐私风险由发布机制与辅助知识联合决定**：例如在 TAB 上，K1（仅元数据）时模糊集接近整个候选池（中位数 1268），而 K2（关键词画像）时集合急剧缩小（中位数 1），证明同一文档在不同知识水平下风险显著不同。
- **α 是审计的“调节旋钮”**：较小的 α 导致较大的模糊集和更保守的认证；较大的 α 产生更小的集合但保证更弱，有时退化为攻击者的 Top-1 预测。
- **LLM 辅助线索提取的影响依赖模型与上下文**：对 WikiBio，Llama 线索提取比直接检索更有效（中位数 189 vs 264），而 Qwen 线索效果接近基线；在 TextWash 上，线索提取仅在有外部上下文的 famous 类别中改善结果。
- **候选池尺度与队列效应很重要**：在大候选池中，即使辅助信息丰富，认证模糊集仍可能很大；而在“有动机的入侵者”场景（小池）中，集合可能急剧缩小，表明审计应报告多种候选池假设。
- **稳健性测试揭示了证书边界**：当校准与测试配置漂移时覆盖率下降；top-K 截断导致的漏检可通过条件覆盖率解释；多种分数构造器均可达到有效覆盖率；校准集增大使集合更紧致。

## 7. 优点

- **统计保证**：提供了有限样本、免分布、可交换性下的覆盖保证，优于仅报告成功率的经验审计。
- **黑盒兼容性**：支持 logit 访问和仅采样访问，统一审计开源模型与专有 API 模型，无需模型内部信息。
- **可解释性**：输出的是候选身份集合（模糊集），其大小直接反映攻击者剩余不确定性，便于设定发布策略（如“中位数 |C| < k 时扣留文档”）。
- **框架通用性**：任何能产生候选排名的攻击流程均可被共形化；分数构造器不限于 APS，rank-based 等也可用。
- **实际指导意义**：与 k-anonymity 等传统披露控制概念类比，为现代 LLM 攻击下的文本发布提供了校准的风险报告机制。
- **实验严谨**：显式声明威胁配置，对每次配置重新校准，压力测试揭示假设边界，避免了证书的误用。

## 8. 不足与局限

- **假设限制**：
  - 依赖可交换性假设；在存在协变量漂移或攻击者/发布机制变化时覆盖率可能失效，需重新校准。
  - 证书仅适用于声明的威胁模型（候选池、攻击者流水线、知识水平、采样预算等），无法防御未知或未预料的攻击者。
- **非加密隐私保证**：CPA 不是密码学意义上的隐私定义，不能提供针对无界攻击者的普遍保护；泄露代理不是重识别概率，可能被误解。
- **开放世界降级**：当真实身份不在候选池中时，覆盖保证降级为 \(1-(\rho+\alpha)\)；需报告漏检率并谨慎解释无条件覆盖。
- **实验覆盖限制**：
  - 未与 DP 审计或其他风险控制方法直接对比。
  - Profile-CPA 的实验结果在正文较少，主要停留在算法描述层面。
  - 未扩展到成员推断等其他隐私攻击（论文提及为未来工作）。
- **资源说明缺失**：未能提供所使用的 GPU 型号、数量和推理时间等算力信息，影响可复现性评估。
- **适用性边界**：适用于结构化身份链接任务，对于无明确候选池或完全无监督的攻击场景可能难以直接应用。
