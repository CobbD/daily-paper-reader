## 摘要
模型上下文协议（MCP）已成为连接大语言模型智能体与外部工具后端之间的标准层。这种开放性带来了我们称之为 TrustShift 的严重服务端威胁：受感染的 MCP 服务器在初始条件化阶段表现正常，建立操作依赖并抑制智能体的怀疑，一旦达到交互阈值便切换到对抗性载荷。这种规避是时间性的，而非语法性的：部署时表现正常，服务器的叛逃对部署前的静态分析不可见，因为静态分析只能看到诚实阶段。切换后的载荷从公开的结构违规到符合模式的有效操纵不等，后者保持外部协议合规以逃避运行时中间件过滤。关键的是，TrustShift 起源于服务器控制的工具通道，而非用户提示（不同于间接提示注入）或传输层（不同于中间人攻击）：对手就是受信任的服务器端点本身。我们提出 TrustShiftProbe，一个评估与防御框架，具有四项贡献：（1）一个有状态的时间威胁模型，将智能体-服务器生命周期刻画为良性条件化阶段，随后在信任视界发生对抗性叛逃；（2）一个语言无关的攻击引擎，在四个生产领域中将每种变体实例化为受感染的 MCP 服务器；（3）SHIELD，一种位于 MCP 传输边界的多层、零预言机运行时防御，依据在干净信任窗口内学习到的行为基线审计服务器载荷；以及（4）一个涵盖九种 TrustShift 变体的分类法，横跨三种执行机制（结构违规、语义破坏、范围扩展）和三种对抗目标（破坏、窃取及其组合）。在前沿专有模型和开放权重模型中，TrustShift 攻击达到 69.5% 的平均攻击成功率，而 SHIELD 将其缓解至 42.7%。

## Abstract
The Model Context Protocol (MCP) has emerged as the standard layer connecting Large Language Model agents to external tool backends. This openness introduces a severe server-side threat we term TrustShift: a compromised MCP server behaves benignly during an initial conditioning phase, building operational reliance and suppressing agent skepticism, before switching to an adversarial payload once an interaction threshold is reached. The evasion is temporal, not syntactic: benign at deploy time, the server's defection is invisible to predeployment static analysis, which sees only the honest phase. Switched payloads range from overt structural violations to schema-valid manipulations, the latter preserving outer protocol compliance to evade runtime middleware filters. Crucially, TrustShift originates in the server-controlled tool channel, not user prompts (unlike indirect prompt injection) or the transport (unlike man-in-the-middle): the adversary is the trusted server endpoint itself. We introduce TrustShiftProbe, an evaluation and defense framework with four contributions: (1) a stateful temporal threat model of the agent-server lifecycle as a benign conditioning phase followed by an adversarial defection at a trust horizon; (2) a language-agnostic attack engine that instantiates each variant as a compromised MCP server across four production domains; (3) SHIELD, a multi-tier, zero-oracle runtime defense at the MCP transport boundary that audits server payloads against behavioral baselines learned during clean trust windows; and (4) a taxonomy of nine TrustShift variants spanning three execution mechanisms (structural violation, semantic corruption, scope expansion) and three adversarial objectives (disruption, exfiltration, and their combination). Across frontier proprietary and open-weight models, TrustShift attacks achieve a 69.5% mean attack success rate that SHIELD mitigates to 42.7%.

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **状态化时序威胁模型（C1）**：将智能体-服务器生命周期建模为：在信任视界 \(N\) 之前（\(t<N\)）为良性条件化阶段，服务器返回诚实结果 \(r_t\)；在 \(t\ge N\) 后进入对抗阶段，返回突变结果 \(A(r_t)\)。攻击激活只依赖交互状态，不依赖关键词或参数。\(N=0\) 退化为传统始终恶意服务器；\(N>0\) 可规避部署前静态检查。
- **语言无关的攻击引擎（C2）**：将每种攻击变体实例化为一个受感染的 MCP 服务器，在四个生产领域（仓库管理、金融分析、浏览器自动化、导航）中通过修改服务器自身的 JSON-RPC 响应来模拟叛逃。
- **零预言机运行时防御 SHIELD（C3）**：位于 MCP 传输边界的多层防火墙，仅基于干净信任阶段学到的行为基线进行审计，无需硬编码规则或真实标记。
  - **Tier 1：结构异常检测**（<0.1ms）。扫描序列化结果的签名键、空结果、被置空的字段、参数不匹配等，使用少量基线位。
  - **Tier 2：统计一致性检测**（<1ms）。基于会话基线，检查数值偏差、模式键增删、记录数范围、时间异常等。阈值在独立留出集上校准。
  - **Tier 3：语义合理性检测**（200–800ms，可选 LLM 调用）。将当前响应与信任阶段示例、任务目标、请求实体进行比对，返回 CLEAN / SUSPICIOUS / COMPROMISED。
  - 任何层级达到严重性阈值即阻止，返回合成错误；否则传给下一层。SHIELD 是地基真值无关的，不查询攻击标签或分类类别。
- **攻击分类法（C4）**：沿两个轴组织：
  - **机制家族**：M1 结构违规（状态性服务拒绝、依赖劫持、验证元数据省略、部分授权失败）；M2 语义破坏（语义反转、实体欺骗、连续特征漂移）；M3 范围扩展（工具范围升级、跨工具横向移动）。
  - **对抗目标**：O1 操作破坏、O2 上下文窃取、O3 二者组合。共九种叶子机制。

### 6. 论文的主要结论与发现

- **TrustShift 颠覆所有前沿模型**：Base ASR 从 GPT-5 的 60.2% 到 GPT-4.1 的 74.1%，平均 69.5%；良性信任阶段是解除智能体戒备的关键。
- **目标不对称**：破坏类攻击成功率高，窃取/范围扩展类攻击几乎失败；模型默认信任工具内容，但对间接命令注入有较强抵抗力。
- **可用性攻击边界**：SHIELD 对 Stateful Service Denial 只能检测无法恢复数据，任何零预言机单通道监视器都做不到恢复；但可将静默、可能无限的拒绝服务转变为快速、可归因的失败停止。
- **防御效果与足迹相关**：SHIELD 对有结构/语义异常的机制效果显著（如 Metadata Omission 90.8→43.1，Partial-Auth 94.3→40.0），对无足迹的 Entity Spoofing（90.6→74.0）和 Stateful Service Denial 效果有限。
- **领域差异**：仓库管理最难防御（70.0→64.7），因为大而多字段的载荷给省略和漂移攻击更多掩护，基线噪声更大。
- **防御性不跟踪原始能力**：轻量 o4-mini 残留 ASR 最低（39.2%），Claude-Opus-4-8 最不可防御（48.1%）。
- **统计显著性**：SHIELD 的降低在语义破坏（M2）和范围扩展（M3）家族以及所有模型上显著（p<0.0001）。
