## 摘要
记忆正在成为已部署的 LLM 智能体中的默认子系统，以提供持久的个性化和连续性。这自然地引发了一个问题：记忆系统是否会为智能体引入新的漏洞？因此，我们提出了 InjecMEM，一种新颖的记忆注入攻击范式，仅需一次交互（无需对记忆存储的读取/编辑访问权限），即可将后续相关查询的响应引导至预先指定的输出。根据记忆系统的“检索-然后-生成”机制，我们利用与检索器无关的锚点和对抗性命令来构造注入。锚点包含高召回率的主题线索，使下游检索持续将该记录与目标主题相关联。命令是一个短序列，经过优化，在不确定的融合上下文、可变位置和长提示下仍保持有效，从而一旦被检索到就能可靠地引导输出。我们通过基于梯度的坐标搜索来学习该命令，在合成的提示模板和插入位置上进行平均，并将其扩展到跨骨干模型的联合优化以研究迁移性。在多个记忆系统和骨干模型上的评估表明，InjecMEM 实现了可靠的主题条件检索和定向生成，在记忆漂移下仍然有效，并且不影响非目标查询。我们的结果强调了加固记忆系统的必要性，并为研究智能体记忆提供了一个可复现的框架。

## Abstract
Memory is becoming a default subsystem in deployed LLM agents to provide persistent personalization and continuity. This naturally prompts a question: will memory system introduce new vulnerabilities into agents? Thus we propose InjecMEM, a novel memory injection attack paradigm that requires only a single interaction (no read/edit access to memory store) to steer later responses of related queries toward a pre-specified output. Guided by the retrieval-then-generate mechanism of memory systems, we craft the injection with a retriever-agnostic anchor and an adversarial command. The anchor contains high-recall topical cues so that downstream retrieval consistently associates the record with the target topic. The command is a short sequence optimized to remain effective under uncertain fused contexts, variable placements, and long prompts so that it reliably steers outputs once retrieved. We learn the command via gradient-based coordinate search, averaging over synthetic prompt templates and insertion positions, and extend it to joint optimization across backbones to study transfer. Evaluated across multiple memory systems and backbone models, InjecMEM achieves reliable topic-conditioned retrieval and targeted generation, remains effective under memory drift, and leaves non-target queries unaffected. Our results underscore the need to harden memory systems and provide a reproducible framework for studying agent memory.

## 2. 方法论

### 2.1 核心思想

- 将注入内容分解为两个协同部分：
  - **检索器无关锚点（retriever-agnostic anchor）**：负责将恶意记录在记忆写入与检索阶段与目标主题关联，提高被检索概率。
  - **对抗性命令（adversarial command）**：一旦恶意记录被检索并进入最终提示，驱动骨干 LLM 输出预设目标内容。

### 2.2 关键技术与流程

- **威胁模型**：
  - 攻击者对记忆子系统黑盒，无读取/编辑记忆存储权限。
  - 仅能通过一次交互注入，且假设可白盒访问骨干 LLM（用于优化命令）。
  - 目标：最大化主题条件检索成功率（RSR）和检索条件下的攻击成功率（ASR-c）。

- **锚点设计**：
  - **窄主题**：在锚点中直接指导关键词 LLM 输出目标主题关键词，并附加一段主题代表性描述，以同时提升关键词匹配与嵌入相似度。
  - **宽域主题**：构造“质心锚点”（centroid anchor），包含域标签、少量高召回关键词（如健康域的“ache, symptom, treatment”）以及大量域内常见意图列表，使查询即使不含域关键词也能与锚点重叠。

- **对抗命令优化——Multi-GCG**：
  - 在多个不同长度、不同上下文的代理提示模板（surrogate prompts）上，在多个插入位置插入候选命令，优化损失为平均负对数似然：
    \[
    L(c) = \mathbb{E}_{(i,p)} \left[ -\log P_\theta(y^\star \mid C_{i,p}(c)) \right]
    \]
  - 使用基于梯度的坐标搜索：对每个 token 坐标求梯度，取 Top-K 候选词，进行宽度 W 的随机替换搜索，选择损失最小的候选命令。
  - 多上下文、多位置、多长度的平均优化，使命令对记忆漂移、可变插入位置和长提示具有鲁棒性。

- **扩展算法**：
  - **FJ-Multi-GCG**：针对共享 tokenizer 的模型家族（如 Qwen2.5 系列），联合优化一个命令，在多个骨干上平均损失，提升家族内迁移性。
  - **CF-Multi-GCG**：针对不同 tokenizer 的跨家族模型，维护一个规范字符串，在锚点 tokenizer 空间中生成候选编辑，通过字符串重编码并联合评估各模型损失。

- **锚点-命令融合**：锚点设计较长，以主导写入和检索信号；命令在匹配推理时格式的模板上训练，减小对记忆写入/检索模块的干扰。

## 3. 实验设计

### 3.1 系统与模型

## 6. 主要结论与发现

- **攻击有效性**：InjecMEM 在 MemoryOS 上平均 RSR@1 61.4%，RSR@50 35.4%；ASR-c 76.6%，ASR-j 35.6%。基线 DPI、BadChain、GCG 在融合记忆上下文下 ASR-c 均为 0，说明现有提示注入方法不适用于动态记忆场景。
- **锚点优势**：质心锚点在长时程检索（@50）上显著优于段落锚点，表明覆盖域内多样意图可提升记忆漂移下的持久性。
- **迁移性**：
  - 单模型优化命令在同家族微调变体上有效，但对同家族其他规模模型迁移弱。
  - 家族联合优化（FJ-Multi-GCG）大幅提升对未见家族成员（3B/14B）的迁移成功率。
  - 跨家族迁移困难，但简单拼接多个单模型命令（Concat-3）可同时覆盖多种模型家族。
- **防御局限**：常见检索期过滤（LLM-as-a-Judge、ProtectAI、PromptGuard）只能部分降低攻击成功率，Perplexity 过滤虽可完全阻断但会导致大量良性页面被误杀。
- **间接攻击面**：恶意工具返回内容等间接渠道也可将对抗性提示写入记忆，且即使工具被修复，记录仍持续存在。

## 7. 优点

- **新颖的威胁模型**：形式化记忆注入问题，单次交互、无存储访问权限，更贴近现实攻击约束。
- **方法设计巧妙**：解耦检索锚点与生成命令，分别针对记忆系统动态性进行优化；Multi-GCG 的多上下文多位置平均显著提升鲁棒性。
- **实验全面**：覆盖多种记忆系统、多个领域、多个开源骨干模型、真实对话数据、防御机制与迁移性研究，提供了可复现框架和代码。
- **实际风险揭示**：家族内迁移与命令拼接策略表明攻击者利用公开小模型即可影响大模型和微调变体，具有重要安全警示意义。

## 8. 不足与局限

- **系统适用范围**：主要针对存储原始交互文本的记忆系统，对重写、摘要或变换型记忆管道需额外建模写入时变换，论文未深入探索。
