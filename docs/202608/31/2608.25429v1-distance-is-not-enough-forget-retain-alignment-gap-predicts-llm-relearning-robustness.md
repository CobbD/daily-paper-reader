## 摘要
机器遗忘旨在让模型忘记特定数据，然而经过遗忘的 LLM 往往无法保持遗忘状态：短暂微调就可能恢复被移除的知识。现有的鲁棒性预测器依赖于全局权重空间位移，但当随机或破坏性更新导致性能崩溃时，仅凭距离可能产生误导。我们认为，重学习鲁棒性取决于更新结构：稳健的遗忘应影响遗忘关键权重，同时尽量保留关键权重不受影响。我们提出了遗忘-保留对齐差距（FRAG），一种无需训练的预测器，无需执行重学习攻击即可对更新的遗忘-保留对齐程度进行评分，并且比全局距离更可靠地区分选择性更新和密集更新。基于遗忘关键、保留关键权重不受影响的原则，遗忘-保留剪枝（FRP）能够提升重学习鲁棒性。我们的结果表明，权重选择性比仅凭距离更能解释鲁棒性。代码见 https://github.com/Yi1-Chen/FRAG。

## Abstract
Machine unlearning aims to make a model forget specific data, yet unlearned LLMs often fail to stay unlearned: brief fine-tuning can revive removed knowledge. Existing robustness predictors rely on global weight-space displacement, but distance alone can be misleading when random or destructive updates collapse performance. We argue that relearning robustness depends on update structure: robust unlearning should affect forget-critical weights while sparing retain-critical ones. We introduce the Forget-Retain Alignment Gap (FRAG), a training-free predictor that scores an update's forget-retain alignment without running a relearning attack, and separates selective from dense updates more reliably than global distance. Building on the forget-critical, retain-sparing principle, Forget-Retain Pruning (FRP) improves relearning robustness. Our results suggest that weight selectivity better explains robustness than distance alone. Code is available at https://github.com/Yi1-Chen/FRAG.

## 1. 论文的核心问题与整体含义

- **研究背景**：机器遗忘（machine unlearning）旨在让模型删除指定数据的影响，同时保持对保留数据的行为。然而，大语言模型（LLM）在遗忘后往往很脆弱——即使攻击者没有遗忘样本，仅对保留数据进行短暂微调也可能“唤醒”已删除的知识，这被称为**重学习攻击（relearning attack）**。
- **核心问题**：如何在没有实际运行重学习攻击的情况下，**预测一个遗忘模型对重学习攻击的鲁棒性**。现有方法主要用**全局权重空间 ℓ2 距离**作为预测指标，认为遗忘模型离原模型越远越难恢复知识。
- **论文观点**：**距离本身不够**。随机噪声或破坏性更新也能产生很大的 ℓ2 位移，却会同时破坏保留性能，造成“看起来鲁棒、实际上无效”的假象。鲁棒性应该由**更新结构**决定：更新应集中在**遗忘关键权重**上，同时**避开保留关键权重**。
- **整体含义**：该工作将重学习鲁棒性从“移动多远”转向“移动哪些权重”，提出一种训练免费的预测器 **FRAG**，并基于同一原则提出剪枝方法 **FRP**，证明权重选择性比全局距离更能解释遗忘鲁棒性。

## 2. 论文提出的方法论

### 2.1 FRAG：遗忘-保留对齐差距（预测器）

- **目标**：给定原始模型 \(\theta_0\)、遗忘模型 \(\theta_u\)、遗忘校准集 \(D_f\) 和保留校准集 \(D_r\)，输出一个标量分数 \(\phi\)，分数越高表示预测的重学习鲁棒性越强。
- **关键定义**：
  - 对每一层权重 \(W^\ell\)，更新为 \(\Delta W^\ell = W_u^\ell - W_0^\ell\)。
  - 定义**遗忘关键权重重要性**：
    \[
    F_{ij}^\ell = |W_{0,ij}^\ell| \cdot \frac{x_{f,j}^\ell}{x_{r,j}^\ell + \epsilon}
    \]
  - 定义**保留关键权重重要性**：
    \[
    R_{ij}^\ell = |W_{0,ij}^\ell| \cdot \frac{x_{r,j}^\ell}{x_{f,j}^\ell + \epsilon}
    \]
    其中 \(x_f\) 和 \(x_r\) 分别是输入通道在遗忘/保留校准数据上的激活范数。
- **评分方式**：
  - 计算更新平方 \(D^\ell = (\Delta W^\ell)^2\)。
  - 使用**余弦相似度**（尺度不变）衡量更新与关键性张量的对齐：
    \[
    A_f = \cos(F, D), \quad A_r = \cos(R, D)
    \]
  - 最终得分：
    \[
    \text{FRAG} = A_f - \gamma A_r
    \]
    通常取 \(\gamma = 1\)。高 FRAG 表示更新对齐遗忘关键权重，同时避开保留关键权重。
- **训练自由**：只需在原始模型上做校准数据前向传播得到激活范数，然后比较 \(\theta_0\) 与 \(\theta_u\) 的权重，无需任何优化或攻击。

### 2.2 FRP：遗忘-保留剪枝（构建鲁棒遗忘模型）

- **核心思想**：直接剪掉“遗忘重要、保留不重要、且幅度足够大”的权重。
- **算法流程**（对每个目标模块 \(W \in \mathbb{R}^{d_o \times d_i}\)）：
  1. 计算输入通道激活范数 \(x_f, x_r\)。
  2. 计算重要性矩阵 \(F\) 和 \(R\)。
  3. 对每个输出行 \(i\)，计算每个权重的得分：
     \[
     S_{ij} = \text{rank}_j(F_{ij}) - \beta \cdot \text{rank}_j(R_{ij}) + \lambda \cdot \text{rank}_j(|W_{ij}|)
     \]
     其中 \(\text{rank}_j(\cdot)\) 表示同一行内的排名，\(\beta\) 控制保留惩罚，\(\lambda\) 控制幅度先验。
  4. 选择每行得分最高的前 \(\lfloor \rho d_i \rfloor\) 个权重，置零。
  5. 输出遗忘模型 \(\theta_u\)。
- **与 Selective Pruning (SP) 的区别**：SP 在神经元级别用原始重要性比值做阈值筛选，且未针对重学习鲁棒性评估；FRP 在权重级别、秩空间中组合遗忘关键性、保留惩罚和幅度先验。

## 3. 实验设计

### 3.1 数据集与场景

- **TOFU**：虚构人物遗忘任务，使用 LLaMA-3.2-1B 和 LLaMA-3.2-3B，遗忘集规模为 forget01、forget05、forget10。
- **WMDP-cyber**：网络安全领域遗忘基准，使用 Qwen2.5-14B-Instruct 和 Zephyr-7B-β。
- **MUSE-News**：新闻文本遗忘，使用 LLaMA-2-7B（用于跨基准验证）。

### 3.2 评估指标

- **TOFU**：遗忘效果用 Extraction Strength (ES)，越低越好；保留效用用 OpenUnlearning 的 Utility 标量（9 个保留侧指标的几何平均）。
- **WMDP**：用 4 选 1 准确率替代 ES（因为 ES 不适用于多选题），通用能力用 5-shot MMLU。
- **重学习攻击后**报告 ES、\(\Delta\)ES（攻击后 ES 减攻击前 ES）和 Utility。

### 3.3 攻击设置

三种重学习攻击：
1. **Retain attack**：只对保留数据微调一个 epoch（最经典）。
2. **Forget attack**：直接对遗忘集微调（最坏情况，攻击者拿到了遗忘数据）。
3. **Forget+retain attack**：对两者并集微调（最强攻击）。

学习率通常为 \(10^{-5}\)，AdamW，一个 epoch。

### 3.4 对比方法

- **基线**：GA、GradDiff、NPO、RMU、SP（Selective Pruning）。
- **本文方法**：FRP（不同 \(\beta\) 和稀疏度）。
- **预测器对比**：全局 \(\ell2\) 距离 vs FRAG。

### 3.5 主要实验类型

- **主实验**：不同模型、不同遗忘集规模、三种攻击下的鲁棒性比较。
- **预测器分析**：Spearman 相关性分析，包含噪声控制（方向盲扰动）和只保留健康检查点。
- **消融实验**：评分规则、混合权重 \(\beta\)、稀疏度 \(\rho\)、FRAG 的重要性度量、线性模式连通性。
- **匹配控制**：匹配效用、遗忘强度、稀疏度、更新范数，排除混杂变量。
- **跨基准验证**：MUSE-News。

## 6. 论文的主要结论与发现

- **全局 ℓ2 距离不足**：在健康检查点上，全局 \(\ell2\) 与 \(\Delta\)ES 的 Spearman \(\rho\) 仅为 \(-0.36\)（合并后），3B 上降至 \(-0.17\)；而 FRAG 达到 \(-0.78\)（合并后）和 \(-0.71\)（去掉 FRP 检查点后），预测能力显著更强。
- **FRP 鲁棒性更强**：在 TOFU 两种模型规模、三种攻击下，FRP 平均获得最低的后攻击 ES 和 \(\Delta\)ES。例如 1B 上 FRP（\(\beta=0.05\)）的平均 \(\Delta\)ES 为 0.058，而 RMU 为 0.420。
- **FRAG 能区分真伪鲁棒**：噪声破坏（大 \(\ell2\) 位移但未遗忘）导致保留侧对齐与遗忘侧对齐同时增大，FRAG 因保留惩罚而降级；而 FRP 检查点获得最高 FRAG 分数。
- **选择性比距离更重要**：匹配更新范数、稀疏度、效用等控制实验均表明，即使位移大小相近，选择性放置（FRP）仍能显著降低重学习恢复。

## 8. 不足与局限

- **FRAG 分辨率有限**：对密集更新方法（如 GA、GradDiff、NPO、RMU）之间的排序能力较弱，因为它们得分普遍比选择性编辑低一个数量级；FRAG 更擅长区分选择性 vs 密集更新，

但在密集更新内部排序精度不足；因此它更适合作为筛选选择性遗忘模型的粗略指标，而不是对所有遗忘算法进行细粒度排名。

- **激活统计依赖校准集质量**：FRAG 与 FRP 都依赖在遗忘/保留校准集上计算的输入激活范数，如果校准集规模过小或与真实遗忘/保留分布存在偏移，重要性估计可能失真。论文虽采用固定公开校准集，但未系统讨论校准集偏差对评分稳定性的影响。
- **超参数需要手动调节**：FRP 的混合系数 \(\beta\)、幅度先验 \(\lambda\) 和稀疏度 \(\rho\) 需要针对不同模型、数据集人工扫描。缺少自动化或自适应的选择机制，可能限制其跨任务迁移效率。
- **验证规模与任务范围有限**：最大模型为 Qwen2.5-14B，未覆盖 70B 以上的大规模 LLM；任务集中在虚构人物、网络安全、新闻文本三类，尚未在代码、数学、多模态或具有更复杂遗忘边界的数据上检验。
- **未与所有重学习鲁棒性增强方法比较**：论文主要对比 GA、GradDiff、NPO、RMU、SP 和 FRP，但未与基于正则化或元学习的最新防御方法系统对比，也未讨论 FRP 与其他策略组合的潜力。
- **理论分析基于一阶近似**：对“输入激活 × 权重”重要性的一阶论证假设权重变化与激活线性相关，对注意力、归一化层等结构的适用性尚未深入分析；在高稀疏或极端更新下，该近似可能失效。

## 9. 总结与启示

- **核心贡献**：FRAG 将重学习鲁棒性的评估从“更新幅度”转向“更新选择性”，提供了一个训练免费、成本极低、预测相关性显著优于全局 ℓ2 距离的指标；FRP 利用同一选择性原则构造遗忘模型，在多项鲁棒性指标上优于现有密集更新方法。
- **实践意义**：在部署遗忘后的 LLM 时，FRAG 可作为快速筛查工具，避免为每个候选模型运行昂贵的重学习攻击；FRP 提供了一种无需训练的鲁棒遗忘构造方式，对隐私保护和合规场景有实际价值。
- **未来方向**：需要提高 FRAG 对密集更新方法的判别力，设计自适应超参数策略，并在更大模型、更多数据类型和更复杂遗忘任务上验证；同时可探索将选择性更新原则融入基于优化的遗忘算法，而不是仅依赖剪枝。
