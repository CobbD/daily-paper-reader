## 摘要
在大型语言模型中控制受限知识对于模型对齐和安全部署至关重要。测试时遗忘通过仅在推理阶段进行干预，避免了昂贵的重训练和参数更新。然而，现有的激活编辑方法施加孤立的逐点修正，忽略了自回归生成如何从提示、缓存和已生成前缀中持续重建隐藏状态。因此，在局部修正成功后，后续状态仍可能回到受限知识区域，导致受限知识重新进入。本文提出基于受限知识边界控制的有状态测试时遗忘（ST$^2$U），将测试时遗忘形式化为轨迹范围的边界控制。ST$^2$U 首先在低维可逆坐标中建模受限知识边界，同时保持正交的非目标分量不变。在推理过程中，ST$^2$U 沿轨迹监测风险，在上下文锚定下施加最小边界修正，并跨 token 传播历史修正状态以缓解知识重新进入。这种轨迹范围的控制能够在保持非目标能力和限制推理开销的同时，实现更持久的遗忘。在三个基准和三个模型系列上，ST$^2$U 取得了最强的整体平衡，兼具最佳或次佳的保留能力与有竞争力的遗忘效果，并且受限知识重新进入的比例远低于测试时基线（13.76%–19.84% 对比 46.50%–59.10%）。

## Abstract
Controlling restricted knowledge in large language models is essential for model alignment and safe deployment. Test-time unlearning avoids costly retraining and parameter updates by intervening only during inference. However, existing activation-editing methods apply isolated pointwise corrections, overlooking how autoregressive generation continually reconstructs hidden states from the prompt, cache, and generated prefix. Consequently, later states may return to restricted knowledge regions after a locally successful correction, causing restricted knowledge re-entry. In this work, we propose Stateful Test-Time Unlearning via restricted knowledge boundary control (ST$^2$U), which formulates test-time unlearning as trajectory-wide boundary control. ST$^2$U first models restricted knowledge boundaries in low-dimensional invertible coordinates while leaving orthogonal non-target components unchanged. During inference, ST$^2$U monitors risk along the trajectory, applies minimal boundary corrections with contextual anchoring, and propagates historical correction states across tokens to mitigate knowledge re-entry. This trajectory-wide control enables more persistent forgetting while preserving non-target capabilities and limiting inference overhead. Across three benchmarks and three model families, ST$^2$U delivers the strongest overall balance, combining best or second-best retention with competitive forgetting and substantially less restricted-knowledge re-entry than test-time baselines (13.76%-19.84% versus 46.50%-59.10%).

## 1. 论文的核心问题与整体含义

- **研究动机**：大型语言模型（LLM）在预训练与微调中可能学习到受限知识（如敏感信息、隐私、版权内容、危险知识），需要在不损害通用能力的前提下抑制这些知识。训练时遗忘成本高昂且可能损害保留能力，因此测试时遗忘（仅推理阶段干预）成为重要方向。
- **核心问题**：现有测试时遗忘方法（尤其是激活编辑类）通常对单个解码位置施加孤立、逐点的修正，忽略了自回归生成过程中隐藏状态会随着提示、缓存与已生成前缀不断重构。局部修正成功后，后续 token 仍可能“漂移”回支持受限知识生成的区域，导致**受限知识重新进入（restricted knowledge re-entry）**。
- **整体含义**：论文将测试时遗忘重新定义为**轨迹范围的边界控制问题**，而非一系列相互独立的点修正，从而提升遗忘的持久性与稳定性。

## 2. 方法论

### 2.1 核心思想
- 提出 **ST²U（Stateful Test-Time Unlearning via restricted knowledge boundary control）**，通过对隐藏状态轨迹进行在线边界控制，在最小化扰动的同时将风险约束在受限知识边界以下，并跨 token 传播历史修正状态以抑制知识重新进入。

### 2.2 关键技术细节

- **受限知识几何建模（Restricted Knowledge Geometry, RKG）**：
  - 利用**配对轨迹**：每个受限序列 $x_i^F$ 对应一个净化参考 $x_i^S$，二者共享上下文但后者省略目标细节，用于对比监督。
  - **低维可逆坐标**：对隐藏状态归一化后，学习列正交基 $U \in \mathbb{R}^{d\times k}$，将状态分解为目标相关坐标 $p = U^\top \tilde{h}$ 与正交残差 $r = (I - UU^\top)\tilde{h}$；再通过可逆映射 $\psi$ 将 $p$ 变换为 $z = \psi(p)$。编辑仅作用于 $z$，残差 $r$ 保持不变。
  - **风险几何**：在 $z$ 空间用核密度估计（KDE）分别建模受限分布 $d_F$ 与净化分布 $d_S$，定义风险 $s(z) = \log d_F(z) - \log d_S(z)$。$s(z) > \tau$ 表示进入风险区域。
  - **上下文参考**：将受限轨迹聚类为 $J$ 个邻域，为每个邻域估计净化参考 $a_j^S$，通过责任权重 $\rho_j^F(z)$ 加权得到上下文锚点 $a(z)$。

- **有状态边界控制（Stateful Boundary Control, SBC）**：
  - **风险触发控制**：若 $s(z_t) \le \tau$，不干预且历史状态衰减 $m_t = \gamma m_{t-1}$；若 $s(z_t) > \tau$，执行边界修正。
  - **法向下降 + 切向历史**：计算梯度 $g_t = \nabla s(z_t)$，得到法向 $n_t$ 与切向投影 $P_t$。方向 $d_t = \text{Normalize}(-n_t + \lambda_m P_t m_{t-1})$，其中历史状态 $m_{t-1}$ 只保留与当前边界切向一致的分量，不会逆转风险下降。步长 $\alpha_t$ 通过线性化约束 $s_t + g_t^\top \Delta z \le \tau$ 计算，并循环修正直至到达边界或达到最大迭代数。
  - **上下文锚定与状态更新**：对边界修正后的状态 $\tilde{z}_t$ 进行软锚定 $z_t^* = (1-\beta_t)\tilde{z}_t + \beta_t a_t$，锚定强度 $\beta_t$ 通过有限回溯选择，且仅接受仍处于边界内且具有足够净化密度支持的状态。最终将 $z_t^*$ 映射回 $p'$，叠加原始残差 $r_t$ 恢复隐藏状态。
  - **历史状态压缩**：将本次修正方向压缩为向量 $v_t$，并根据风险违反程度计算门控 $q_t$，更新固定维度状态 $m_t = \gamma m_{t-1} + (1-\gamma) q_t v_t$。预填充阶段因果扫描以初始化 $m_n$，解码阶段继续同一状态递推，无需存储完整激活历史。

### 2.3 公式/算法流程（文字说明）
- 整体优化目标：在满足每一步风险约束 $R_F(h_t(\Delta h_{<t}) + \Delta h_t) \le \tau$ 的条件下，最小化所有位置扰动 $\Delta h_t$ 的 $\ell_2$ 范数之和。
- 实际中通过局部代理目标（式 7）逼近：最小化 $z$ 空间扰动平方，同时保持历史切向对齐并满足线性化风险约束。
- 推理流程：输入 prompt → 逐 token 计算隐藏状态 → 映射至风险几何 → 若超边界则执行法向+切向修正、锚定、状态更新 → 恢复隐藏状态 → 继续生成。

## 6. 主要结论与发现

- ST²U 在三个基准、三个模型家族上取得**最强或次强的保留能力**，同时保持有竞争力的遗忘性能。
- **受限知识重新进入率大幅降低**：ST²U 的 R-Ent 为 13.76%–19.84%，而测试时基线为 46.50%–59.10%，证明轨迹范围控制有效抑制了知识重新进入。
- 消融实验证实：
  - 移除历史状态会显著增加 R-Ent（+23.74），但对 MMLU 影响很小，说明历史状态主要提供时间持久性。
  - 移除风险门控导致 WMDP 平均上升 13.09、R-Ent 上升 32.99、MMLU 下降 5.03，说明风险条件干预对选择性和有效性至关重要。
  - 移除正交残差保留导致 MMLU 下降 7.79，表明残差是保留非目标知识的关键。
- 层-wise 分析显示低维可逆坐标在 16 层中有 13 层优于直接隐藏层引导，且放宽了对干预层的选择敏感性。
- 部署成本上，ST²U 在遗忘/保留指标上优于 SCANS 和 RMU，同时离线准备时间仅 2.8 分钟，在线延迟 2.21×，整体部署成本具有竞争力。

## 7. 优点

- **新颖的问题视角**：首次系统识别并量化“受限知识重新进入”现象，将测试时遗忘从逐点修正提升为轨迹控制。
- **方法设计巧妙**：
  - 低维可逆坐标仅编辑目标相关子空间，保留正交残差，有效减少语义漂移。
  - 法向下降与切向历史结合，既降低风险又保持时间一致性。
  - 固定维度历史状态机制轻量且可跨 token 传播，无需存储完整激活历史。
- **实验全面且具有针对性**：
  - 自定义 R-Ent 指标直接衡量论文核心主张，而非仅看最终遗忘率。
  - 消融、层-wise 分析、攻击、部署成本等多维度验证。
  - 跨三个不同架构模型家族，增强了泛化性证据。
- **部署开销可控**：离线准备时间短，在线延迟仅为 2.21×，优于部分基线。

## 8. 不足与局限

- **实验覆盖仍有局限**：
  - 仅测试了 LLM 的受限知识遗忘，未涉及多模态或更广泛任务。
  - 模型规模主要在 7B–14B，未验证更大规模模型（如 70B+）。
  - 攻击实验为“有限白盒”设定，攻击者能力受限；未测试更复杂的黑盒提取或自适应攻击。
- **开销方面**：虽然离线准备时间短，但在线延迟 2.21× 仍高于 AS 和 RMU 等参数更新方法，可能对延迟敏感场景不够理想。论文也指出未来需研究更稀疏的触发策略和自适应干预时间表以降低在线开销。
- **理论保证不足**：方法主要依赖局部线性化与启发式锚定，缺乏全局收敛或持久性保证；风险边界由 KDE 密度比估计，可能对低密度区域不稳定。
- **超参数敏感性与可迁移性**：虽然展示了统一阈值的鲁棒性，但风险维度、邻域数、耦合块数等离线几何超参数的选择依据未深入讨论；不同任务或模型可能需要重新调整。
- **未明确说明的部分**：论文未给出完整的训练/准备时间（除主实验离线 2.8 分钟外），也未报告所有模型家族的详细能耗或显存占用，可能影响可复现性评估。
- **潜在的偏差风险**：净化参考序列的构造质量会直接影响风险几何，若净化序列未能完全去除目标知识或被错误标注，可能导致风险边界偏差；论文未详细分析这一敏感性。
