## 摘要
专家混合（Mixture-of-Experts, MoE）架构通过路由机制选择性激活专家子网络，实现了可扩展且高效的大语言模型（LLMs）。然而，这种自适应设计引入了新的攻击面：特定专家与某些 token（如序列结束符）产生不成比例的相关性，使攻击者能够通过轻量扰动操纵模型行为。在本工作中，我们提出 Groundhog 位翻转攻击（GBFA），这是首个针对基于 MoE 的大语言模型的基于位翻转的拒绝钱包（Denial-of-Wallet）可用性攻击。通过识别并翻转与相关专家激活关联的路由层位，我们证明 GBFA 在对话、推理和智能体任务三种不同 LLM 模式下显著延长了解码 token 使用量，同时基本保持语义保真度。在四个主流真实基于 MoE 的大语言模型中，平均手动停用不到 4 个专家即可使平均输出膨胀至 5912%，大多数测试样本达到最大 token 数。这些结果揭示了 MoE 架构对位翻转的鲁棒性漏洞，并凸显了 GBFA 作为针对大语言模型的可用性攻击的潜力。

## Abstract
Mixture-of-Experts (MoE) architectures enable scalable and efficient large language models (LLMs) by selectively activating expert sub-networks through a routing mechanism. However, this adaptive design introduces a new attack surface: specific experts become disproportionately correlated with certain tokens (e.g., end-of-sequence), allowing adversaries to manipulate model behavior via lightweight perturbations. In this work, we present \textbf{Groundhog Bit-Flip Attack (GBFA)}, the first bit-flip-based \textit{ Denial-of-Wallet availability attack} against MoE-based LLMs. By identifying and flipping routing-layer bits associated with related expert activations, we demonstrate that GBFA substantially extends the decoding token usage across three different LLM modes: conversational, reasoning, and agentic tasks, while largely preserving semantic fidelity. Across four main real-world MoE-based LLMs, manually deactivating on average fewer than \textbf{4 experts} drives average output inflation to $\mathbf{5912\%}$, with the majority of test samples reaching max tokens. These results reveal a robustness vulnerability of MoE architectures to bit flip, and highlight the potential of GBFA as an availability attack against LLMs.

## 1. 论文的核心问题与整体含义

- **研究背景**：专家混合（MoE）架构通过路由机制在每个 token 上仅激活少数专家，大幅降低大语言模型推理成本，已被 Mixtral、DeepSeek、Qwen3、GPT-OSS 等主流模型采用。
- **核心问题**：MoE 稀疏激活虽然带来效率优势，但路由机制使部分专家与序列结束符（EOS）、思考结束符（EOT）等终止类 token 高度相关。攻击者可以通过轻量参数扰动（如位翻转）破坏这些专家的激活，导致模型难以产出终止 token，被迫持续生成，形成针对“按 token 计费”推理服务的拒绝钱包（Denial-of-Wallet, DoW）攻击。
- **整体含义**：本文首次将位翻转攻击从传统的模型完整性破坏（如精度下降、输出损坏）转向可用性攻击，揭示 MoE 路由层是一个局部、易受攻击的结构性脆弱点，对 LLM 服务成本和稳定性构成现实威胁。

## 2. 论文提出的方法论

- **威胁模型**：
  - 攻击者是与受害模型共置的普通租户，无需特权或物理访问；
  - 具备白盒访问模型参数（开放权重）；
  - 可通过 Rowhammer、电压毛刺等硬件故障注入手段翻转 DRAM 中的模型权重位；
  - 目标是在保持语义连贯、避免检测的前提下最大化输出 token 长度。

- **三步攻击流程（GBFA）**：
  1. **目标相关专家识别**：
     - 计算目标 token（如 EOS）位置与非目标 token 位置之间的专家激活频率差异（routed expert 用 $\tau_{l,i}$，shared expert 用门控值偏移 $\Delta g_{l,i}$）。
     - 分数高者即为与终止行为强相关的专家。
  2. **目标专家检测**：
     - **GLOBAL**：全局对专家按分数排序，超过阈值的专家被选为目标专家；
     - **LOCAL**：逐层选择 top-k 专家并进行临时停用，测量输出长度变化，选出影响最大的层 $l^*$ 及其专家；
     - 两种方法在计算成本和精度上形成互补。
  3. **路由层位翻转攻击**：
     - 缓存目标层隐藏状态，避免重复前向传播；
     - 对每个目标专家的路由权重或偏置逐位翻转，重新计算路由 logits 和专家激活频率，定义位翻转有效性 $BF\text{-}eff(b) = \frac{EAF_i^{orig} - EAF_i^{(b)}}{EAF_i^{orig}}$；
     - 每个专家选取 top-B 个有效位，实现用极少位翻转抑制目标专家。

- **在线执行**：攻击者通过 Rowhammer 等方法翻转已部署模型中的目标位，由于权重修改是持久的，一次攻击可影响后续所有查询。

## 6. 论文的主要结论与发现

- MoE 大模型存在明显的**专家–token 专业化**：少数专家主导 EOS/EOT 等终止 token 的生成。
- 只需手动停用平均不到 **4 个专家**，即可使四个主流 MoE 模型的平均输出膨胀达 **5912%**，多数样本达到 max token 上限。
- 位翻转攻击（GBFA）在保持较少专家修改的同时，能实现与手动停用相近的输出膨胀效果；GPT-OSS 因可攻击偏置参数，效果接近手动停用。
- 攻击在对话、推理、智能体规划三类任务中均有效；在智能体编码 plan 模式下，GLOBAL 停用使平均计划 token 增加 501.5%，10 个沙箱均达最大步数。
- 攻击同样适用于 EOT token，可迫使模型持续思考直至耗尽 token 预算。
- 模型性能在多数配置下保持可接受水平（PPL 低于 10），但 DeepSeek 在 GLOBAL 位翻转下出现严重语言退化，提示攻击隐蔽性存在模型差异。
