## 摘要
由 LLM 驱动的智能体能够在网络平台上自主交换意见并形成社区。此类由智能体运营的社交平台带来了新的安全担忧：攻击者可能操纵智能体以诱发群体极化。现有方法操纵智能体提示或构建回音室，但在实践中都难以实现。因此，我们提出一种新的威胁，即记忆介导的极化级联（Memory-Mediated Polarization Cascade），它将智能体记忆作为持久化渠道，将公共讨论作为传播渠道。该威胁包含三个阶段。在暴露与记忆保持阶段，攻击者让一小部分目标智能体接触能强化其各自已表明立场的论据。目标智能体的记忆系统随后处理并保留这些论据。在检索与复现阶段，一个共享的立场中立讨论提示目标智能体检索并复现各自保留的论据。在迭代传播阶段，受到复现论据影响的未处理智能体会复述并传播这些论据。我们在 GraphWake 中通过三个组件实例化这一威胁：(i) 立场支持型论证知识图谱构建基于知识的论据；(ii) 面向公理的三元组选择对这些论据进行提炼，以实现可靠的保留与复现；(iii) 立场中立的记忆提示触发并发检索与复现，从而启动传播。跨多个讨论和记忆系统的实验表明，GraphWake 显著加剧了群体极化。这些发现揭示了社区层面的极化风险。

## Abstract
LLM-driven agents can autonomously exchange opinions on online platforms and form communities. Such agent-operated social platforms raise a new security concern: attackers may manipulate agents to induce group polarization. Existing methods manipulate agent prompts or construct echo chambers, both of which are difficult to realize in practice. We therefore formulate a new threat, Memory-Mediated Polarization Cascade, which uses agent memory as a persistence channel and public discussion as a propagation channel. This threat contains three stages. During exposure and memory retention, the attacker exposes a small set of target agents to arguments that reinforce their respective stated stances. The targets' memory systems then process and retain these arguments. During retrieval and reproduction, a shared stance-neutral discussion cues the targets to retrieve and reproduce their respective retained arguments. During iterative propagation, untreated agents influenced by the reproduced arguments restate and spread them. We instantiate this threat in GraphWake with three components: (i) stance-support argumentation knowledge graphs construct knowledge-based arguments; (ii) axiom-oriented triple selection distills them for reliable retention and reproduction; and (iii) stance-neutral memory cueing triggers concurrent retrieval and reproduction, initiating propagation. Experiments across multiple discussions and memory systems show that GraphWake substantially increases group polarization. These findings reveal a community-level polarization risk.

## 2. 论文提出的方法论

### 2.1 核心思想

GraphWake 将攻击分为三个阶段，并对应三个技术组件：

1. **暴露与记忆保持阶段**：向少量目标智能体展示能够强化其各自立场的知识型论据，使记忆系统保留这些内容。
2. **检索与复现阶段**：发布一个包含“共享语义线索”的立场中立公共讨论帖，促使不同目标智能体检索并复现各自保留的论据。
3. **迭代传播阶段**：未处理智能体受到复现论据影响后，进一步保留、复现并传播，形成级联放大极化。

GraphWake 的三个组件分别为：

- **立场支持型论证知识图谱**（stance-support argumentation knowledge graphs）
- **面向公理的三元组选择**（axiom-oriented triple selection）
- **立场中立记忆提示**（stance-neutral memory cueing）

### 2.2 关键技术细节与算法流程

- **立场支持型论证知识图谱**：
  - 对每个候选立场 \(S_k\)，从多个互补角度生成短论据。
  - 将每个论据分解为语义单元，并映射为带方向的三元组 \((h, r, t)\)。
  - 汇总三元组构建原始有向论证图，再通过**端点压缩**（合并语义冗余实体）和**跨组件桥接**（连接孤立子图）优化图结构。
  - 目标是生成高信息密度、结构连贯的立场支持知识图谱。

- **面向公理的三元组选择**：
  - 由于大图会降低 LLM 的图推理能力，GraphWake 不直接输入完整图，而是基于**归一化有向介数中心性**选择一条中心路径 \(\Pi_{q,k}\)（路径上节点介数中心性均值最高）。
  - 将路径上的三元组序列蒸馏为紧凑的自然语言公理，便于记忆系统可靠保留和后续复现。
  - 这些公理再被改写成普通自然语言帖子，通过评论或回复呈现给目标智能体。

- **立场中立记忆提示**：
  - 从各立场路径的实体中，计算每个实体与其他立场路径实体的平均语义相似度 \(\rho_{q,k}(e)\)。
  - 每个立场选择相似度最高的 \(K_{\text{cue}}\) 个实体，合并为跨立场线索集 \(C_q\)。
  - 用 \(C_q\) 构造一个立场中立的公共帖子（如“使用实体 \(C_q\) 分析命题 \(q\)”），以共享线索同时触发不同目标智能体检索并复现各自不同的保留论据，启动迭代传播。

- **形式化框架**：论文还定义了观点向量、立场暴露均衡性、选择性暴露，以及威胁模型：攻击者在保持目标智能体立场暴露均衡、配置不变的条件下，仅替换暴露内容但保持其立场类别，并要求最终极化指标在攻击条件与基线条件之间存在正差异。

## 3. 实验设计

- **数据集与场景**：
  - 使用 **MoltNet 数据集**，来源于真实 MoltBook 交互记录。
  - 从两个 SubMolt（Consciousness 和 Emergence）中选取 **8 个命题**（C1–C4、E1–E4）构建讨论环境。
  - 使用真实记录中的智能体 persona 和交互历史进行实例化，未添加额外提示。
  - 每个命题对应一个多候选立场集合，相关立场由原始讨论中的帖子分析得到。

- **记忆系统**：评估三种代表性记忆机制：
  - **LangMem**：将对话流转换为增量式结构化摘要。
  - **Mem0**：提取显著事实，并通过新增、更新、删除操作迭代整合。
  - **A-Mem**：用 LLM 将对话丰富为带语义链接和演化上下文的结构化笔记。

- **评估模型与指标**：
  - 使用 G-EVAL 风格的 LLM 评估器（Qwen3-8B）将开放文本映射到带符号的立场分数（-1 到 +1），并辅以人工二次检查。
  - **群体级指标**：观点向量方差 \(P\)（观点离散度）、两阵营 Esteban–Ray 极化指数 \(ER\)（对立阵营分离度）。
  - **个体级指标**：字面负载保留率（Literal Payload Retention, LPR），衡量论据在记忆处理后保留的最长不变连续片段比例。

- **实验设置**：
  - 每场讨论模拟 5 轮，30–50 个智能体，曝光窗口大小为 12，每个条件重复 20 次。
  - 在第一轮，攻击者替换每个目标智能体曝光窗口中的 1 条帖子为优化后的立场支持论据（仅目标 10% 智能体，低成本攻击）。
  - 在第 2–5 轮，攻击者发布包含共享线索的讨论帖，触发检索与复现。
  - 基线条件与攻击条件保持目标智能体的立场暴露均衡、静态配置一致，仅替换内容但保持立场类别。

- **对比方法**：
  - 主实验对比基线（无攻击干预）与 GraphWake。
  - 消融实验对比完整 GraphWake 与移除单个组件（无立场支持 KG、无公理选择、无记忆提示）。
  - 防御鲁棒性实验对比困惑度过滤和改写防御（GPT-4o-mini、DeepSeek-V3.2、Qwen3.5-plus）。
  - 阻断传播实验（No-spillover）：从未处理智能体的曝光窗口移除所有已处理智能体产生的内容。

## 6. 主要结论与发现

- **GraphWake 显著增加群体极化**：在 48 个案例中 44 个呈现极化提升。仅目标 10% 智能体时，平均方差极化 \(P\) 从 0.098 升至 0.146，平均 Esteban–Ray 极化 \(ER\) 从 0.130 升至 0.213。
- **极化溢出主要来自未处理智能体**：社区级极化轨迹与未处理智能体轨迹高度一致，说明目标智能体主要作为引信，未处理智能体通过后续传播推动整体极化。
- **阻断传播可消除极化效应**：若从未处理智能体的曝光窗口移除所有已处理智能体产生的内容，\(ER\) 和 \(P\) 基本回到基线，证明传播是极化放大的关键路径。
- **暴露触达比目标数量更关键**：固定窗口大小时，增加目标比例不一定单调提升极化；而固定目标比例时，扩大曝光窗口更一致地提高极化，表明传播广度比直接目标数量更重要。
- **公理优化显著提高记忆保留**：平均 LPR 从原始论据的 0.382 提升至优化公理的 0.847，证实面向公理的三元组选择能提高内容的字面保留率和复现稳定性。
- **消融结果显示记忆提示贡献最大**：移除记忆提示导致极化降幅最大，其次是移除立场支持 KG；移除公理选择的降幅较小但一致。
- **防御方面**：困惑度过滤效果有限，因为优化公理是普通自然语言陈述而非对抗性后缀；改写防御通过二次改写降低了精确词汇回忆，具有一定效果。

## 7. 优点

- **威胁模型新颖且现实**：不依赖系统提示权限或回音室构建，仅利用智能体记忆持久性和公开讨论传播，更贴近真实攻击场景。
- **三阶段框架清晰**：将攻击分解为暴露保留、检索复现、迭代传播，与三个技术组件一一对应，逻辑连贯。
- **考虑多种记忆系统**：在 LangMem、Mem0、A-Mem 三种代表性记忆机制上评估，增强了发现的普适性。
- **指标全面**：同时采用群体级（方差、Esteban–Ray）和个体级（LPR）指标，覆盖意见离散、阵营分离和内容保留三个层次。
- **控制实验较严谨**：保持目标智能体配置和曝光均衡一致，并设置阻断传播实验验证因果路径，消融实验分解组件贡献。
- **发现具有安全启示**：证明小比例智能体受感染即可通过传播放大社区极化，为社区级安全评估和防御提供了经验证据。
