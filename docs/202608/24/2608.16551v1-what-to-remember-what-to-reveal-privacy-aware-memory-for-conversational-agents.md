## 摘要
长期记忆使个性化对话智能体能够在会话之间保留用户信息。然而，现有记忆架构主要优化效用，却忽视了不必要地存储和重用个人可识别信息（PII）等隐私属性所带来的风险。在个性化记忆中应对隐私风险具有挑战性，因为简单删除敏感值可能会削弱系统效用。因此，记忆智能体的隐私保护应当管控敏感值的整个生命周期，而不仅仅是对单条记录进行脱敏。为弥补这一不足，我们提出了脱敏隐私映射记忆（SP-Mem），一种隐私感知的记忆架构，将记忆效用与精确隐私值的暴露解耦。SP-Mem 提供了全生命周期隐私设计，从原始用户输入中识别并分离敏感信息，将脱敏内容和精确隐私值存储在隔离结构中，并根据任务需求和用户同意选择性地检索隐私值。我们进一步引入了隐私感知记忆基准，联合评估响应质量、隐私行为和推理成本。在多个基于LLM的智能体上的大量实验表明，SP-Mem 在实现更强个性化的同时减少了不必要的隐私暴露。代码和数据可在 https://github.com/Jensassss/SP-Mem 获取。

## Abstract
Long-term memory enables personalized conversational agents to retain user information across sessions. However, existing memory architectures primarily optimize for utility while neglecting the risks of unnecessarily storing and reusing private attributes such as personally identifiable information (PII). Addressing privacy risks in personalized memory is challenging because simply removing sensitive values can undermine system utility. Therefore, privacy protection for memory agents should govern the full life cycle of sensitive values rather than only sanitizing individual records. To address this gap, we introduce Sanitized Privacy-Mapped Memory (SP-Mem), a privacy-aware memory architecture that decouples memory utility from exact private-value exposure. SP-Mem provides a full life-cycle privacy design that identifies and separates sensitive information from raw user inputs, stores sanitized content and exact private values in isolated structures, and selectively retrieves private values based on task requirements and user consent. We further introduce a privacy-aware memory benchmark that jointly evaluates response quality, privacy behavior, and inference cost. Extensive experiments across multiple LLM-based agents show that SP-Mem achieves stronger personalization while reducing unnecessary privacy exposure. Code and data are available at https://github.com/Jensassss/SP-Mem.

## 1. 论文的核心问题与整体含义

- **研究背景**：长期记忆让对话智能体跨会话保留用户信息，但现有记忆架构主要优化个性化效用，对个人可识别信息（PII）等隐私风险关注不足。
- **核心矛盾**：一方面，敏感信息会自然出现在用户交互中，直接存入可检索记忆可能在无关任务中被泄露；另一方面，很多个性化任务（如填表、金融/健康协助）需要精确私有值，不能简单删除或永久屏蔽。
- **研究定位**：隐私保护不应只对单条记录脱敏，而应覆盖敏感值“写入—存储—检索—使用”的完整生命周期。
- **主要贡献**：提出 SP-Mem（Sanitized Privacy-Mapped Memory），将记忆效用与精确私有值暴露解耦，并构建首个隐私感知记忆基准，联合评估响应质量、个性化、隐私行为和推理成本。

## 2. 论文提出的方法论

SP-Mem 包含三个关键组件：

### 2.1 隐私感知记忆写入
- 采用**向量记忆 + 图记忆**互补结构：
  - 向量分支存储事实型自然语言记忆，支持语义检索。
  - 图分支存储关系三元组 `(源实体, 关系, 目标实体)`，支持结构化访问用户属性与偏好。
- 在写入前，使用**基于规则的隐私抽取策略**检测敏感值，为每个私有值标注类型 `(vj, τj)`。
- 对检测到的私有值进行脱敏后再写入搜索记忆；非私有事实和关系保持不变。

### 2.2 分区存储与隐私映射
- 存储层分为三部分：
  1. **可搜索记忆**：存储非私有条目和脱敏表示（向量/图）。
  2. **隐私映射层**：记录脱敏条目与精确私有值的映射键。
  3. **受保护私有存储**：仅存储精确私有值。
- 精确私有值不进入通用检索，只能通过授权恢复。

### 2.3 查询时隐私感知推理与授权检索
- 查询分析器识别任务所需信息，判断是否涉及私有实体。
- 若不需要私有信息：仅从脱敏搜索记忆检索。
- 若需要私有信息：先请求用户同意；有同意则通过映射层恢复任务所需精确私有值，否则仅使用脱敏记忆。
- 最终基于查询与检索到的上下文生成回复。

### 2.4 脱敏策略
四种策略：
- 名称/别名替换
- 后缀保留掩码（如保留后四位）
- 数值分桶（如年龄分组、收入等级）
- LLM 泛化（如将具体职业泛化为“医疗专业人员”）

- **消融**：向量+图混合记忆显著优于单一分支，说明两者互补。

## 7. 优点

- **全生命周期隐私设计**：覆盖写入、存储、检索、授权恢复，而非仅对单次提示脱敏。
- **解耦效用与隐私**：脱敏记忆保留任务相关语义，精确私有值单独保护，兼顾个性化与安全。
- **混合记忆架构**：向量与图分支互补，同时支持语义召回和结构化关系访问。
- **基准设计细致**：区分偏好与私有信息，覆盖多种任务模式和同意条件，能够评估“何时该用、何时不该用”隐私信息。
- **多模型验证**：在四种不同骨干 LLM 上验证，增强结论稳健性。
- **隐私与质量联合评估**：不仅看回答好不好，还看隐私请求是否恰当、是否泄露不必要私有值。

## 8. 不足与局限

- **数据合成性**：用户画像、对话、任务均为合成，可能无法完全覆盖真实交互中的模糊、不完整和动态变化。

  - 泛化属性可能仍支持重识别；
  - 多轮交互可能带来的推理攻击；
  - 对脱敏值的恢复攻击。
- **算力细节缺失**：未报告 GPU 数量、总推理时长等资源开销细节。
- **LLM-as-judge 偏差风险**：尽管做了顺序交换处理，裁判模型仍可能存在未知偏见。
- **应用限制**：未在真实用户验证场景中评估，也未支持更细粒度的用户自定义隐私偏好。
- **授权模型简单**：当前主要基于任务类型与二元同意，真实场景可能需要更复杂的上下文授权。
