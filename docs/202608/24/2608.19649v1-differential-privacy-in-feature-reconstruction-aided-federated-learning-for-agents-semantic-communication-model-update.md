## 摘要
本文提出一种基于具有语义特征重构的联邦学习算法（FedSFR）的差分隐私联邦学习框架，用于训练面向图像传输的语义通信模块。通过允许上行容量不佳的客户端传输从本地训练的联合信源信道编码（JSCC）编码器提取的低维语义特征向量，FedSFR在异构无线条件下提升了通信效率和训练稳定性。为保护客户端隐私，我们引入单次拉普拉斯机制，并在理论上证明：在相同通信预算下，基于特征的传输相比基于梯度的传输能够实现严格更强的差分隐私（DP）保障。此外，引入一种模型选择机制以缓解隐私保护扰动造成的性能下降。在多个数据集上的实验结果表明，所提出的差分隐私辅助的FedSFR在异构无线系统中的训练稳定性和图像重建质量方面优于差分隐私使能的FedAvg。

## Abstract
This paper proposes a differentially private federated learning (FL) framework built upon an FL algorithm with semantic feature reconstruction (FedSFR) for training semantic communication modules for image transmission. By allowing clients with unfavorable uplink capacity to transmit low-dimensional semantic feature vectors extracted from locally trained joint source-channel coding (JSCC) encoders, FedSFR enhances communication efficiency and training stability under heterogeneous wireless conditions. To protect client privacy, we incorporate the oneshot Laplace mechanism and theoretically demonstrate that feature-based transmission achieves strictly stronger differential privacy (DP) guarantees than gradient-based transmission under an identical communication budget. In addition, a model selection mechanism is introduced to alleviate performance degradation caused by privacy-preserving perturbations. Experimental results on multiple datasets show that the proposed DP-aided FedSFR outperforms DP-enabled FedAvg in training stability and image reconstruction quality in heterogeneous wireless systems.

## 二、论文提出的方法论

### 2.1 FedSFR 基础框架

- 系统包含一个参数服务器（PS）和 K 个客户端，客户端本地维护 JSCC 模型 \(w=\{\theta,\phi\}\)，其中 \(\theta\) 为编码器参数，\(\phi\) 为解码器参数。
- 每轮全局迭代中，参与的客户端集合 \(A^{(t)}\) 被分为两组：
  - \(A_m^{(t)}\)：信道条件较好，上传**稀疏化的本地梯度更新**（top-S 稀疏化 + 误差反馈）。
  - \(A_o^{(t)}\)：信道条件较差，上传**从本地更新后的编码器提取的低维特征向量**（对公共数据集 \(P_k\) 生成）。
- 服务器首先聚合 \(A_m^{(t)}\) 的梯度更新得到中间模型 \(w^{(t+1/2)}\)，然后利用来自 \(A_o^{(t)}\) 的特征向量构建特征数据集 \(D_s^{(t+1/2)}\)，通过服务器端特征重构（FR）进一步微调全局模型，最终得到 \(w^{(t+1)}\)。
- 特征传输的通信优势：特征维度 \(d \ll N\)（总参数量），因此在相同上行预算下可以传递更多信息。

### 2.2 差分隐私集成：Oneshot Laplace 机制

- 采用两种机制组合：
  - **Oneshot 机制**：先对查询结果添加拉普拉斯噪声，再私有地选择 top-S 索引（不泄露真实排序）。
  - **Laplace 机制**：进一步对选中索引对应的数值添加拉普拉斯噪声，隐藏具体幅度。
- 两种传输策略的隐私处理：
  - **梯度传输（策略 i）**：对完整 JSCC 模型更新 \(g_k^{(t)} \in \mathbb{R}^N\) 应用 OL 机制，隐私化整个模型的稀疏更新。
  - **特征传输（策略 ii）**：仅对编码器侧更新 \(g_{k,\theta}^{(t)} \in \mathbb{R}^{N/2}\) 应用 OL 机制，然后再用隐私化后的编码器生成特征向量。
- 关键思想：特征生成仅依赖编码器，因此只需对约一半的模型参数进行隐私化，从而降低敏感度，提升隐私保证。

### 2.3 模型选择（Model Selection, MS）算法

- 动机：DP 噪声会污染用于特征重构的编码器参数，导致服务器基于噪声特征进行 FR 时可能产生次优模型。
- 做法：服务器利用共享公共数据集 \(P = \bigcup_k P_k\)，比较中间模型 \(w^{(t+1/2)}\) 与 FR 后模型 \(w^{(t+1)}\) 的图像重建 MSE，选择误差更小的模型作为本轮全局模型。
- 效果：减少噪声特征对训练轨迹的负面影响，提高训练稳定性和最终性能。

### 2.4 差分隐私理论分析（Theorem 1）

- 假设本地更新 \(g_k^{(t)}\) 有界（\(L_1\) 范数 ≤ \(G^{(t)}\)），且编码器-解码器架构大致对称。
- 在相同上行通信预算 \(S\) 下：
  - 梯度传输的 DP 参数：\(\epsilon^{(i)} = \frac{2SG^{(t)}(\sigma_1 + 2\sigma_2)}{N\sigma_1\sigma_2}\)
  - 特征传输的 DP 参数：\(\epsilon^{(ii)} = \frac{SG^{(t)}(\sigma_1 + 2\sigma_2)}{N\sigma_1\sigma_2}\)
- 因此 \(\epsilon^{(i)} = 2\epsilon^{(ii)}\)，说明特征传输在相同预算下提供**严格更强**的 DP 保证（隐私损失减半）。
- 该优势来源于特征传输只需对编码器（约 N/2 参数）进行隐私化，敏感度约为完整模型的一半。

## 三、实验设计

### 3.1 数据集与场景

- **主要数据集**：CIFAR-10（3×32×32 RGB 图像）。
- **扩展数据集**：CelebA（用于验证在高分辨率场景下的适用性）。
- **信道场景**：异构无线环境，客户端上行链路经历瑞利衰落 \(h \sim \mathcal{CN}(0,1)\)，信道容量随时间变化，稀疏化水平 \(S_k/N\) 约在 0.05～0.25 之间动态变化。
- 默认训练信噪比（SNR）为 20 dB，部分实验测试 10 dB。

### 3.2 实验设置

- 总客户端数 \(K=50\)，每轮参与 \(K_m + K_o = 20\) 个客户端（部分参与）。
- 模型：JSCC 编码器含 5 层卷积，解码器含 5 层转置卷积，总参数量约 0.32M；特征维度 \(d=256\)。
- 阈值 \(S_{th}/N = 0.15\) 用于划分 \(A_m^{(t)}\) 和 \(A_o^{(t)}\)，平均 \(K_o \approx 10\)。
- 学习率：服务器初始 \(\eta_s^{(0)}=0.001\)，客户端初始 \(\eta_c^{(0)}=0.01\)，每 10 轮衰减 0.9；批大小 16，训练 3 个 epoch。
- 评估指标：峰值信噪比（PSNR）。

### 3.3 对比方法

- **FedAvg+OL**：将 OL 机制直接应用于 FedAvg 的梯度传输。
- **FedAvg+OL (ideal)**：由于原始 FedAvg+OL 在异构无线环境中训练失败，作者增加了理想化设置（固定稀疏化水平 \(S_k/N=0.2\) 或 0.1，且 \(K_o=10\)）以进行公平比较。
- **FedSFR+OL**：引入 OL 机制但未加入模型选择。
- **FedSFR+OL+MS**：本文提出的完整方法。
- **FedSFR+OL+MS (privacy)** 与 **(power)**：
  - privacy：使用较小噪声（\(\sigma_1=\sigma_2=0.0005\)），使隐私水平与 FedAvg+OL 相同（\(\epsilon^{(i)}=\epsilon^{(ii)}\)）。
  - power：使用较大噪声（\(\sigma_1=\sigma_2=0.001\)），使隐私水平是 FedAvg+OL 的两倍（\(\epsilon^{(i)}=2\epsilon^{(ii)}\)）。

## 六、论文的主要结论与发现

- **特征传输具有天然 DP 优势**：在相同上行预算下，仅隐私化编码器即可实现严格更强的差分隐私保证（\(\epsilon\) 减半），这是 FedSFR 结构带来的固有优势，且不限于 OL 机制。
- **模型选择算法有效**：MS 算法通过比较 FR 前后模型在公共数据集上的重建性能，显著提升了 DP 噪声下 FedSFR 的训练稳定性和最终 PSNR，尤其在训练后期。
- **FedSFR+OL+MS 优于 FedAvg+OL**：在所有测试的噪声水平、信道条件和数据集上，所提方法在图像重建质量和收敛速度上均优于 DP 使能的 FedAvg，且对异构无线环境具有显著更强的鲁棒性。
- **噪声分配的影响**：增大 \(\sigma_1\)（oneshot 索引选择噪声）比增大 \(\sigma_2\)（Laplace 幅度噪声）对性能的损害更大，说明保护 top-S 索引选择过程的隐私对模型训练更为关键。
- **阈值 \(S_{th}\) 存在最优区间**：过大或过小都会降低性能，适中的 \(S_{th}/N \approx 0.15\) 能平衡梯度聚合与特征重构的贡献。
