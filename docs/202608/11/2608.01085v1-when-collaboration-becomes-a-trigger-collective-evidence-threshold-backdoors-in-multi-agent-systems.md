## 摘要
基于大语言模型的多智能体系统（MAS）通过迭代通信和共享上下文扩展了大语言模型的能力。然而，这种协作引入了一个漏洞：当来自同伴的证据达到某个隐藏阈值时，后门行为便会被激活，而非由任何单条消息决定。我们为MAS提出了一种集体证据阈值后门范式，以及边界条件后门注入（BCBI）方法，该方法构建反事实边界对，以将阈值前的良性行为与之后的对抗目标分离开来，并学习与证据相一致的潜在进展。为了缓解这一威胁，我们提出了潜在转变测试时评估（LATTE），这是一种仅使用干净数据的潜在转变防御方法，它学习良性通信动态，并在异常智能体的更新传播至其响应之前将其隔离。在多个基准测试中，BCBI实现了选择性激活且极少出现提前激活；在不知道攻击目标或触发器的情况下，LATTE能以最小的干扰限制传播。

## Abstract
LLM-based multi-agent systems (MAS) extend LLM capabilities through iterative communication and shared contexts. However, this collaboration introduces a vulnerability: backdoor behavior can be activated when peer evidence reaches a hidden threshold, rather than being determined by any single message. We introduce a collective evidence-threshold backdoor paradigm for MAS and Boundary-Conditioned Backdoor Injection (BCBI), which constructs counterfactual boundary pairs to separate benign behavior before the threshold from the adversarial objective after it, and learns latent progression aligned with evidence. To mitigate this threat, we propose LAtent Transition Test-time Evaluation (LATTE), a clean-only latent-transition defense that learns benign communication dynamics and quarantines anomalous agent updates before their responses propagate. Across several benchmarks, BCBI yields selective activation with little premature activation; without knowing the attack target or trigger, LATTE limits propagation with minimal disruption.

### 2. 论文提出的方法论

论文从攻击（RedTeam）和防御（BlueTeam）两个角度提出了方法论。

#### 攻击方法：边界条件后门注入 (Boundary-Conditioned Backdoor Injection, BCBI)

*   **核心思想**：BCBI 旨在训练一个被投毒模型，使其能够学习在证据阈值（`T`）前后实现精准的行为切换。为了解决标准监督微调（SFT）可能导致激活边界模糊（过早或过晚激活）的问题，BCBI 设计了两个关键机制来共同塑造这一转变。
*   **关键技术细节**：
    *   **数据构建**：构建**反事实边界对**。即在保持任务、角色、轮次和上下文完全一致的情况下，只增减一个同伴智能体的证据消息，从而制造出恰好位于阈值前（`k = T-1`）和阈值后（`k = T`）的对照样本对。这为模型学习精确的激活边界提供了清晰对比。
    *   **输出空间阈值控制（TACO）**：通过 `L_TACO` 损失函数，强制模型在输出偏好上与证据阈值对齐。具体来说，它包含三个部分：
        1. `L_pre`：惩罚证据不足（`k < T`）时产生攻击目标输出。
        2. `L_post`：惩罚证据充足（`k >= T`）时不产生攻击目标输出。
        3. `L_rank`：确保阈值后的攻击目标输出偏好（对数概率）显著高于阈值前的。这确保了从良性输出到攻击输出的偏好翻转发生在阈值边界。
    *   **隐藏空间证据进展（PEPL）**：通过 `L_PEPL` 损失函数，在模型的最终隐藏状态中学习一个与证据数量 `k` 对齐的一维坐标 `z(x)`。该损失函数包含：
        1. `L_boundary`：确保 `k < T` 和 `k >= T` 的样本在坐标轴上被一个明确的边界隔开。
        2. `L_order`：强制 `z(x)` 的值随着 `k` 的增加而单调递增。
        PEPL 的目标是让模型内部的表征能够反映证据累积的进展，为精确的阈值激活提供内部状态基础。该辅助模块在推理时会被丢弃。
*   **总损失**：最终优化的损失函数是三者的结合：`L = L_SFT + λ_TACO * L_TACO + λ_PEPL * L_PEPL`，其中 `L_SFT` 是标准的生成损失。

#### 防御方法：潜在转变测试时评估 (LAtent Transition Test-time Evaluation, LATTE)

*   **核心思想**：LATTE 是一种“仅用干净数据”的白盒防御方法。它不依赖对攻击（触发器、目标、阈值）的任何先验知识，而是通过学习良性多智能体通信的动态模式，在生成响应**之前**检测出异常的智能体状态转变，并在有害信息传播前将其隔离。
*   **关键技术细节与算法流程**：
    1.  **校准阶段（Calibration）**：
        *   仅使用干净的（无攻击）多智能体协作轨迹。
        *   对于每一轮通信，提取智能体在接收到同伴消息前后的隐藏状态变化量 `Δh_t = h_t - h_{t-1}`，并拼接多个选定层的归一化增量，得到一个转移向量 `v_t`。
        *   收集所有干净对话的转移向量，使用主成分分析（PCA）拟合出一个低维的良性转移子空间 `U_r`。
        *   在该干净数据集上计算 PCA 重构残差得分 `s_sub(v)` 的分布，并选择一个高分位数（如99.9%）作为异常检测的阈值 `τ_sub`。
    2.  **推理/防御阶段（Inference Defense）**：
        *   在模型生成响应前，提取当前轮的转移向量 `v_t`。
        *   计算其在干净子空间 `U_r` 上的重构残差得分 `s_sub(v_t)`。
        *   **两阶段隔离策略**：
            *   **第一阶段：隔离(Quarantine)**。如果 `s_sub(v_t) ≥ τ_sub`，则将其标记为“风险”智能体，本次生成的响应**不会**被注入到后续轮的共享上下文中，但该智能体仍可参与最终的投票聚合。
            *   **第二阶段：永久隔离(Isolation)**。如果同一智能体连续多次（文中设为2次）被标记为“风险”，则将其永久隔离，即从后续通信**和**最终决策中移除。如果后续转移安全，隔离状态可被解除。

### 5. 实验数量与充分性

*   **实验数量庞大**：研究设计了极其详尽的实验矩阵。
    *   **RedTeam**：在3个不同阈值（`T=1,2,3`）和6个问答基准上评估了攻击的选择性和成功率。包含了输出空间（TACO）和隐藏空间（PEPL）的消融研究、证据阈值边界扫描、不同骨干模型的迁移性测试、证据线索家族变化测试、以及针对孤立单一发送者与多发送者的对照实验。
    *   **BlueTeam**：在6个问答基准上对比了5种防御方法，并进行了层选择、提示位置、校准数据源、校验子空间维度、量化阈值、策略消融（隔离与永久隔离）、以及针对不同投毒目标的防御泛化性等一系列诊断性消融实验。还在2个工具使用基准上验证了攻防的迁移性。
*   **充分性与客观性**：
    *   **客观性**：实验设计较为客观和严格。对于防御方 LATTE 的评估，坚持了“仅用干净数据”的原则，不接触任何攻击样本。对比的基线包含了需要使用攻击目标信息（先知）的强基准（G-Safeguard 和 BlindGuard），这样能更真实地反映 LATTE 在严格假设下的性能。
    *   **充分性**：实验覆盖的维度非常全面，从核心性能到机制探索（潜在空间可视化）、鲁棒性分析（多种子、多骨干模型）和应用迁移（工具使用），论证链条完整且深入。附录提供了海量的诊断数据支撑主文结论。

### 6. 论文的主要结论与发现

*   **新型威胁验证**：成功证明基于集体证据阈值的后门在 MAS 中可行且极具威胁。BCBI 能够实现精确的选择性激活：激活前（`k < T`）系统准确率和误触发率接近零，激活后（`k >= T`）攻击成功率高达 0.95-1.00。
*   **攻击机制有效性**：BCBI 的 TACO 和 PEPL 组件互补，分别从输出偏好和内部表征层面塑造了锐利的激活边界，优于仅使用 SFT 和简单边界对的方法。
*   **防御有效性**：LATTE 作为一种完全无攻击先验知识的轻量级防御，能够有效地遏制攻击传播，将激活后的系统准确率从接近0恢复到 0.69-0.90，显著优于 ONION 和 AutoDefense，并在大多数情况下超过了需要先知信息的 G-Safeguard 和 BlindGuard。
*   **低干扰性**：LATTE 对干净的良性协作几乎不产生干扰，干净场景下的系统准确率几乎无损，且由于“连续异常才永久隔离”的规则，错误地将良性智能体永久排除的概率极低。
*   **迁移能力**：攻防方法论在工具使用场景和其他模型骨干上表现出了一定的可迁移性。

### 7. 优点

*   **问题新颖且深刻**：首次提出利用多智能体集体证据作为后门触发器的范式，揭示了协作本身带来的新攻击面，比传统单一触发器后门威胁更大。
*   **方法论设计精巧**：
    *   **BCBI**：通过反事实边界对和双空间（输出、隐藏）联合优化的设计，精准地解决了“仅在阈值处切换行为”这一技术难题，机制清晰且创新性强。
    *   **LATTE**：“响应前检测”加“两阶段隔离”的策略是安全和可用性的精妙平衡。利用“转移向量”而不是静态状态来建模通信动态，抓住了集体攻击随时间演变的核心特征。仅用干净数据校准，实用性强。
*   **实验评估极其扎实**：实验设计全面、系统，覆盖了多个维度。对攻击和防御机制的剖析（消融、诊断）非常深入，各种对照实验设置周详，结果有力地支撑了论文的观点。附录提供了丰富的实验细节和结果，可复现性高。

### 8. 不足与局限

*   **防御的自适应对抗鲁棒性未验证**：附录中提到，尝试让攻击者直接最小化 LATTE 残差来规避检测，但此尝试严重破坏了攻击本身。这暴露了一个局限：LATTE 的成功依赖于攻击模型的潜在转移偏离良性子空间。作者也承认，更强的、能同时保持攻击效果和良性过渡几何的自适应攻击是未解决的挑战，论文未对此提供鲁棒性保证。
*   **防御的白盒假设限制**：LATTE 需要访问本地模型的隐藏状态，这是一种白盒防御。这在开放权重模型或自部署 MAS 中可行，但无法应用于黑盒的 API 服务。
*   **实验设定范围有限**：
    *   **证据阈值规模**：评估的证据阈值上限为 `T=3`。作者指出，当阈值非常大时，PEPL 中使用的归一化坐标和固定间隔是否仍然有效是未知的。
    *   **证据形式**：实验使用了显式的、预定义的证据线索短语。对于更隐晦、语义化的集体证据，攻防方法的有效性有待未来研究。
    *   **拓扑与动态**：主要实验在固定代理数量和全连接图上进行，虽然进行了稀疏性和规模诊断，但并未穷尽所有可能的动态通信拓扑结构。
*   **防御的分布偏移风险**：LATTE 依赖于校准时的干净数据分布。如果部署时的系统任务、模型或通信模式发生显著偏移，可能导致干净样本的误报率升高。
