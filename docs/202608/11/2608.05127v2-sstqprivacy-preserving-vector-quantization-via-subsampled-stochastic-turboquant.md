## 摘要
在分布式优化中实现局部差分隐私同时保持低通信成本仍然具有挑战性。现有的向量量化方法（如vqSGD）使用高维几何构造，但会带来不利的维度相关方差。在这项工作中，我们提出了子采样随机TurboQuant（SSTQ），这是一个结合了过完备等范紧框架、坐标子采样和隐私感知一维量化的框架。SSTQ包括两种变体：一种扁平化随机响应版本和一种度量感知拉普拉斯版本，后者更适合较宽的码本位宽场景。我们证明，SSTQ在客户端仅使用$\lceil \log_2 N \rceil + b$比特的情况下实现了最优均方误差缩放，其中$N = Θ(d)$是框架大小。我们还推导了一个替代的隐私感知码本目标，将码本相关的MSE缩放从$O(4^b)$降低到$O(2^b)$。最后，我们在使用CIFAR-10和Fashion-MNIST的联邦学习任务上对SSTQ与已有基线进行了实证评估，展示了良好的效用和通信效率。部分分析推导首次使用了谷歌内部开发的基于Gemini的全自动代理系统获得。作者已验证这些推导并对其进行了编辑以使表述更清晰。

## Abstract
Achieving local differential privacy in distributed optimization while maintaining low communication cost remains challenging. Existing vector quantization methods, such as vqSGD, use high-dimensional geometric constructions but incur unfavorable dimension-dependent variance. In this work, we propose Subsampled Stochastic TurboQuant (SSTQ), a framework that combines overcomplete equal-norm tight frames, coordinate subsampling, and privacy-aware one-dimensional quantization. SSTQ includes two variants: a Flat Randomized Response version and a Metric-Aware Laplace version, the latter being better suited to higher codebook bit-width regimes. We show that SSTQ achieves optimal mean squared error scaling while using only $\lceil \log_2 N \rceil + b$ bits per client, where $N = Θ(d)$ is the frame size. We also derive a surrogate privacy-aware codebook objective that reduces the codebook-dependent MSE scaling from $O(4^b)$ to $O(2^b)$. Finally, we empirically evaluate SSTQ against established baselines on federated learning tasks using CIFAR-10 and Fashion-MNIST, demonstrating favorable utility and communication efficiency.   Some of the analytical derivations were first obtained using a fully automated Gemini-based agentic system developed internally at Google. The authors have verified those derivations and edited them for clarity of presentation.

    *   这两个目标在本质上是矛盾的：压缩要求将高维信号映射到紧凑的离散表示，而LDP则需要注入噪声以保证输出具有“合理的否认性”。

### 2. 论文提出的方法论

*   **核心思想**：通过三大技术组件的融合，将高维向量的隐私保护量化问题转化为一个**一维的、隐私感知的标量量化问题**，从而规避了高维几何带来的维数灾难。
    1.  **过完备等范紧框架（Kashin表示）**：将原始高维向量`x`变换到一个维度`N`更高（红）的`N`维空间。该表示保证了新向量`y`的每个坐标分量都有统一且较小的上界（`∥y∥∞ ≤ K / √N`），避免了信息集中于单一坐标。
    2.  **数据无关的坐标子采样**：从`N`个Kashin系数中**随机均匀地采样一个坐标索引`j`**，仅对该标量`yⱼ`进行量化和传输，极大地降低了通信量。
    3.  **隐私感知的一维量化**：对采样的标量`yⱼ`进行量化（随机舍入到相邻的码字），然后应用隐私机制进行扰动。论文提出了两种扰动机制以适应不同场景。

*   **关键技术细节与变体**：
    *   **算法流程（SSTQ）**：
        1.  **编码（客户端）**：输入`x` -> 计算Kashin表示`y` -> 随机采样坐标`j` -> 将标量`yⱼ`随机量化到码本`Γ`中的某个标记`v`（如`cₖ`或`cₖ₊₁`）-> 应用LDP机制将`v`扰动成`z` -> 传输元组`(j, index_of(z))`，通信成本为 `⌈log₂ N⌉ + b` 比特。
        2.  **解码（服务器）**：接收`(j, z)` -> 从`z`无偏恢复出标量估计值`ỹⱼ` -> 构建一个只有第`j`个位置非零的稀疏向量`ỹ` -> 通过Kashin框架的逆变换重构原始向量的估计`ẋ`。
    *   **两种LDP扰动变体**：
        *   **扁平化随机响应（Flat-RR）**：在所有`M=2ᵇ`个码字上进行均匀的随机响应。其优点是实现简单、估计无偏，但缺点是方差会随码本大小`M`线性增长。
        *   **度量感知拉普拉斯机制（Metric-Aware Laplace）**：引入一种连续-离散混合机制。首先从以真实标记`v`为中心的截断拉普拉斯分布中采样一个连续值`T`，然后将其量化到最近的码字`z`。该方法利用后处理特性满足LDP，通过在解码端使用“恒等解码”（直接使用接收到的`z`），以**一个维度无关的小偏差**为代价，换取了**不随`M`指数增长的方差**，适合多位（高`b`值）量化场景。
    *   **隐私感知码本优化**：
        *   针对Flat-RR变体，论文推导出一个**代理优化目标`L_SSTQ`**。该目标将量化误差和LDP噪声方差统一建模，仅依赖于码本几何和Kashin边界`B`，而**与具体数据分布无关**。
        *   通过最小化该目标，得到的优化码本能够将Flat-RR的MSE对码本大小`M=2ᵇ`的依赖从 `O(4ᵇ)` 降至 `O(2ᵇ)`，实现指数级改进。
