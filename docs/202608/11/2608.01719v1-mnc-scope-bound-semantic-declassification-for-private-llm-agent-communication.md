## 摘要
多智能体大语言模型（LLM）系统即使在公开输出看起来无害时，也可能通过内部消息、工具参数、日志和持久化记忆暴露受保护状态。现有的隐私提示、遮盖方法和源级访问控制限制了表面内容或数据访问，但并未规定合法知情的智能体应披露什么，或者这些披露可能如何被下游重用。我们引入了最小必要通信（MNC），这是一种带类型的语义降密协议，它从应用编写的候选系列中选择任务充分的披露，并将其绑定到明确的接收者、目的、转发、生命周期、日志和记忆范围。引用监视器在后续操作中强制执行这些范围，而历史感知扩展则考虑了重复披露所积累的推理风险。受控的语义连接、记忆、探测和纵向实验表明，传统防御在保留协议级效用的同时，可能暴露大量的额外推理信号。在相同的接收文本下，MNC保留了授权交付，同时阻止了纯文本语义降密器允许的未授权转发、日志记录、持久存储和过期后的检索。双骨干MAGPIE执行进一步表明，代理披露在后续的规划、工具使用、协调和记忆检索中传播。这些结果支持范围内语义降密作为私密LLM-Agent系统的一种实用的通信边界。

## Abstract
Multi-agent large language model (LLM) systems can expose protected state through internal messages, tool arguments, logs, and persistent memory even when their public outputs appear innocuous. Existing privacy prompts, redaction methods, and source-level access controls restrict surface content or data access, but do not specify what a legitimately informed agent should disclose or how that disclosure may be reused downstream. We introduce Minimum-Necessary Communication (MNC), a typed semantic-declassification protocol that selects a task-sufficient disclosure from an application-authored candidate family and binds it to explicit recipient, purpose, forwarding, lifetime, logging, and memory scopes. A reference monitor enforces these scopes across subsequent operations, while a history-aware extension accounts for inference risk accumulated over repeated disclosures. Controlled semantic-join, memory, probing, and longitudinal experiments show that conventional defenses can preserve protocol-level utility while exposing substantial additional inference signal. Under identical receipt text, MNC preserves authorized delivery while blocking unauthorized forwarding, logging, durable storage, and retrieval after expiration that a text-only semantic declassifier permits. Two-backbone MAGPIE executions further show that mediated disclosures propagate through subsequent planning, tool use, coordination, and memory retrieval. These results support scope-bound semantic declassification as a practical communication boundary for private LLM-agent systems.

*   **整体含义**：本文提出了一种名为“最小必要通信”（MNC）的类型化语义降密协议，通过显式地限定披露信息的接收者、目的、转发、生存期、日志和记忆范围，并由引用监视器强制执行，来解决内部通道中信息过度共享与二次泄露的问题。

### 2. 论文提出的方法论
*   **核心思想**：将代理间的私密通信建模为基于显式应用接口的类型化语义降密问题。系统不从无限的文本空间中生成，而是在应用预定义的有限候选族（candidate family）中，选择一个任务充分且风险最低的披露，并为此披露绑定可强制执行的元数据范围。
*   **关键技术与协议流程**：
    *   **合约与范围（Contract & Scopes）**：每次披露关联一个合约 `c = (p, r, F, l, φ, μ)`，明确授权目的 `p`、接收者 `r`、允许的字段 `F`、生存期 `l`、允许的下游接收者 `φ` 和是否允许写入记忆 `μ`。
    *   **引用监视器**：在运行时，监视器在每次发送、转发、日志记录、记忆写入和读取前检查对应的范围约束。衍生对象可以缩小但绝不能放宽原始范围（范围单调性）。
    *   **披露选择（Disclosure Selection）**：对于给定的合约 `c`，从候选族 `D_c` 中选择风险 `R` 最小的候选 `d*`，该候选必须通过合约验证且对下游操作是充分的。
    *   **历史感知变体（MNC-L）**：在核心变体（MNC-C）基础上，引入累积披露预算 `B` 和逐事件风险增量 `ΔR_t`，通过记录历史披露的累积风险，防止多次看似有限的披露逐渐揭示隐私状态。
    *   **失败处理（MNC-D）**：当无安全候选时，可选择将计算委托给可信代理、放弃操作或请求用户批准。

### 6. 论文的主要结论与发现
*   **传统防御不足**：隐私提示、脱敏和访问控制在任务级行为上可能表现正常，但内部通道仍残留显著的推理信号（如Raw下攻击者超额准确率0.326）。
*   **MNC有效降低泄露**：MNC-C将超额推理泄漏降至0.035，同时任务成功率还高于原始共享（0.567 vs 0.373）。接收文本约束是首跳隐私获得的主要来源。
*   **范围强制执行是关键增益**：在接收文本相同的情况下，纯文本语义降密器无法阻止范围违规（违规率0.999），而MNC将违规率降至0.004，同时保持0.996的合法交付率。
*   **历史感知缓解累积风险**：MNC-L通过预算扫描在隐私（超额泄漏0.012–0.062）和任务效用（成功率0.421–0.567）之间描绘出可调节的帕累托前沿。
*   **委托处理无安全收据场景**：在纠缠任务中，MNC-L+D通过委托可信代理，将任务成功率从0.641恢复至0.804，同时将暴露降至0.016。

### 7. 优点
*   **问题视角新颖**：明确指出问题不仅在于“谁能访问”，更在于“合法知情的代理应向下游披露什么”以及“披露后如何控制二次使用”，填补了当前研究的空白。
*   **机制设计完整**：将内容选择、风险估计、范围绑定和历史感知整合为统一的协议，通过引用监视器保证运行时强制，提供了从发布到使用全程的可控性。
*   **实验评测严格且分层**：分离了内容改写本身带来的收益与范围强制执行带来的额外收益，剥离清晰；采用多模型、多攻击者集成和大量统计重采样，增强了结论的稳健性。
*   **实际可操作性**：不对模型自行发现最优披露做不切实际的假设，而是将“最小必要”定义在应用显式提供的候选族内，贴近实际部署。

### 8. 不足与局限
*   **安全假设较强**：协议依赖于应用方正确编写合约、候选族和风险估计器，并假设引用监视器本身不会被绕过，即信任计算基要求较高。
*   **模型与规模有限**：实验仅在7-8B参数的指令模型上开展，未涉及更大规模或商用API模型，其结论在更强推理能力模型上的泛化性有待验证。
*   **任务复杂性**：所采用的任务场景仍相对受控，实际应用中候选族和任务充分性验证器的设计本身可能非常困难，且特定领域的偏差风险未充分讨论。
*   **效率与失败模式**：历史感知和委托策略引入了额外的推理开销和失败模式（如代理无法集成经纪人的收据导致下游重规划失败），效用-隐私平衡的操作点选择可能需要领域专家介入。
*   **攻击者覆盖**：尽管采用了五种攻击者，但攻击能力仍有限，未测试基于LLM的强自适应攻击者，可能低估隐私风险。
