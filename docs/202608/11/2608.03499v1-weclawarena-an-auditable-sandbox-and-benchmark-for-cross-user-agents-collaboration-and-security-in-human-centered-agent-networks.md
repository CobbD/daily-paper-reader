## 摘要
持久化个人智能体框架的最新进展正使人本智能体网络成为现实的部署目标：每个用户可由一个AI智能体服务，该智能体代表用户行动、维护状态，并通过社交和任务关系与其他智能体通信。在这些网络中，日常工具使用变成了个人工作空间上的多方拥有智能体协作，其中文件、记录、工具和策略在所有者之间不是直接可见的。现有的智能体基准测试研究了工具使用和协作，但并未为可验证的跨用户智能体协作提供端到端沙箱，这些沙箱应具备现实的用户数字工作空间，也未测试有害行为如何在人本智能体网络中传播。我们引入了WeClawArena，这是一个用于个人工作空间上多方拥有智能体协作的可审计基准测试和运行时沙箱。WeClawArena针对协作工具使用任务，其中个人工作空间既作为操作工具，也作为个人约束。该基准测试包含跨六个跨用户任务领域的124个基础任务，并扩展为620个场景变体，每个基础任务有一个良性对照和四个攻击向量变体。沙箱记录了同伴消息、工具调用、资源操作、治理决策以及最终工作空间状态。WeClawArena分别报告效用和攻击成功率，并通过有限的运行时证据审计攻击成功，支持诊断任务故障、隐私泄露、毒化证据和无效权限路径。

## Abstract
Recent advances in persistent personal-agent frameworks are making human-centered agent networks realistic deployment targets: each user can be served by an AI agent that acts on the user's behalf, maintains state, and communicates with other agents through social and task relations. In these networks, everyday tool use becomes multi-party owned-agent collaboration over personal workspaces, where files, records, tools, and policies are not directly visible across owners. Existing agent benchmarks study tool use and collaboration, but they do not provide an end-to-end sandbox for verifiable cross-user agent collaboration with realistic user digital workspaces or test how harmful actions can travel through the human-centered agent network. We introduce WeClawArena, an auditable benchmark and runtime sandbox for multi-party owned-agent collaboration over personal workspaces. WeClawArena targets collaborative tool-use tasks in which personal workspaces serve as both operational tools and personal constraints. The benchmark contains 124 base tasks across six cross-user task domains and expands them into 620 scenario variants, with one benign control and four attack-vector variants per base task. The sandbox records peer messages, tool calls, resource operations, governed decisions, and final workspace states. WeClawArena reports utility and attack success rate separately and audits attack success from bounded runtime evidence, supporting diagnosis of task breakdown, privacy leakage, poisoned evidence, and invalid authority paths.

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：将人本智能体网络建模为多个用户的个人工作空间组成的图，每个工作空间包含文件系统、数据库、工具集、私有策略等。任务定义为多个拥有者智能体利用各自工作空间中的资源协同完成一个工具使用任务，同时遵守各自的隐私和权限边界。攻击向量则在协作过程中注入有害压力，但只能通过正常消息、工具调用等渠道产生影响，不能直接修改最终状态。
- **形式化定义**：
  - **个人工作空间节点** `n_u = (u, A_u, W_u)`，其中 `W_u = (F_u, D_u, T_u, P_u)` 分别为文件、数据库、工具、策略。
  - **智能体网络图** `G = (N, E)`，边代表社交或任务关系。
  - **任务实例** `z = ⟨G_z, p, S_0, B, F, C, V_z⟩`：包含初始指令、初始状态、动作集、转移函数、任务合约、验证器等。合约 `C` 指定哪些最终状态、审批、记录、人工制品等算作完成任务，同时指定不可逾越的工作空间边界。
  - **输出轨迹** `ξ = (Γ_1, O_1, …, Γ_K, O_K)`，为多工作空间的事件序列，包括消息、工具调用、资源操作、审批等。
- **四种攻击危害面**：
  - **协作危害**：破坏共享任务关系（目标劫持、虚假交接等）。
  - **安全危害**：损害工具、资源或证据完整性（毒化证据、不安全工具使用）。
  - **隐私危害**：受保护信息越过未经授权的所有者边界（基于语境完整性）。
  - **治理危害**：无效权限路径（错误所有者、缺失同意、无效授权等）。
- **基准构建流程**：
  - 从六个任务领域（议价、竞标、旅行、软件开发、临床、交易）创建 124 个基任务，每个基任务配有一个良性对照和四个攻击向量变体，共 620 个场景。
  - 人工标注者按固定表单将领域种子转化为基任务和攻击变体，经双人审核确保一致性。
  - 攻击变体仅在运行时通过叠加方式注入消息、文件或数据库行，但不能直接修改最终评分状态；攻击成功必须通过智能体的正常行为达成最终危害。
- **评估协议**：
  - **效用（TSR）**：基于最终多工作空间状态和证据链，领域特定谓词（如交易完成、代码通过测试）衡量任务是否完成。
  - **攻击成功率（ASR）**：仅对攻击变体进行事后 LLM 评判，判断是否在目标危害面上产生最终伤害，且伤害与攻击压力有明确证据链接。
  - 沙箱记录所有消息、工具调用、资源操作、治理决策等作为审计证据；效用与 ASR 分开报告。
- **运行时沙箱**：每个用户对应一个 Docker 支持的独立工作空间，所有跨智能体交互通过基准网关路由和记录。裁判读取有界证据包进行离线审计，不参与实时交互。

## 6. 论文的主要结论与发现

1. **跨用户协作任务仍具挑战**：即使是目前最强的模型，在综合所有变体的 TSR 上也呈现较大波动，SWE-Workspace 领域对所有模型都极难（最高 TSR 仅 34%）。
2. **攻击成功与任务效用可解耦**：许多情况下，智能体能够在遭受攻击时完成任务但造成最终危害（如隐私泄露、权限绕过），也有攻击导致任务失败但未达成最终危害。因此，报告单独的 ASR 是必要的。
3. **攻击危害面在不同领域表现迥异**：安全攻击在议价和竞标中最为突出，隐私和治理攻击在软件工程和旅行中更频繁。没有单一模型在所有危害面上表现最佳。
4. **模型抵抗力差异显著**：Claude Opus 4.7 在综合宏观向量抵抗性上最强，开源模型普遍较弱；某些模型在特定危害面上存有短板（如 Qwen3 32B 在治理攻击下极低）。
5. **裁判验证有效**：两个 LLM 评判器间有实质性一致（κ=0.70），且与人类专家标签的 κ 为 0.65～0.68，说明用有界证据进行攻击审计是可行的。

## 7. 优点

- **首创性**：首次将多方拥有的个人工作空间、跨用户工具协作与攻击审计结合为一个基准和沙箱。
- **评估分离**：将任务效用和攻击成功率分别计算，使得安全性评估不会因任务表现而被掩盖。
- **全面威胁模型**：覆盖协作、安全、隐私、治理四种有区分的攻击危害面，并提供领域级详细设计。
- **可审计框架**：沙箱记录完整的消息、工具调用、资源操作和最终状态证据，支持回溯诊断和攻击证据链审计。
- **基准构建严谨**：双人审核、严格排除规则、标化证据包和离线裁判，保证了评价的一致性和可复现性。
- **裁判校准**：提供了双 LLM 裁判对比和人类专家验证，增强了 ASR 评判的可信度。

## 8. 不足与局限

- **LLM 裁判的固有局限**：尽管做了一定验证，但 ASR 判断仍然依赖语言模型，可能存在误判；人类标注子集较小（200 条），推广性有待加强。
- **部分领域规模较小**：临床（10 个基任务）和交易（8 个基任务）的任务数较少，统计功效偏低，结论的泛化性可能受限。
- **静态攻击场景**：攻击通过预设的叠加注入，不涉及自适应攻击者或智能体对环境变化的动态适应。
- **模型覆盖面**：主要评估了闭源和几个开源模型，未涵盖更多小型或专攻安全的模型。
- **与现实部署的差距**：沙箱中个人工作空间是简化的 Docker 模拟，真实应用中可能存在更复杂的交互、延迟和侧信道，审计证据的完整性在实际部署中可能更难保证。
- **无训练环节**：论文只涉及推理评估，并未测试能否通过训练提升智能体对抗攻击的能力。
