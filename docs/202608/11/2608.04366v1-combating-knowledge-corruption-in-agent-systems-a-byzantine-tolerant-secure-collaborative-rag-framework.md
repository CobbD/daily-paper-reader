## 摘要
尽管检索增强生成系统部分解决了大语言模型中的幻觉问题，但也引入了知识腐蚀攻击的新漏洞。对手利用这些漏洞毒化RAG系统提供的文档，以操纵大语言模型的输出。为了应对这一威胁，我们提出了SecureCollaRAG，一个利用多源知识验证机制的容忍拜占庭故障的协作RAG框架。我们的方法通过基于动态图神经网络的可靠性评分，使代理系统能够安全地验证文档来源，有效防止隐蔽的知识腐蚀攻击，同时保持必要的领域知识完整性。通过广泛的评估和形式化分析，我们证明SecureCollaRAG在非独立同分布数据下对攻击者保持鲁棒性。

## Abstract
While retrieval-augmented generation systems partially address the hallucination issues in large language models, it also introduces new vulnerabilities to knowledge corruption attacks. Adversaries exploit these vulnerabilities by poisoning documents provided by RAG system to manipulate LLM outputs. To counter this threat, we propose SecureCollaRAG, a Byzantine-tolerant collaborative RAG framework leveraging Multi-source Knowledge Validation Mechanism. Our approach enables agent system to securely verify document provenance through dynamic GNN-based credibility scoring, effectively preventing stealthy knowledge corruption attacks while preserving essential domain knowledge integrity. Through extensive evaluations and formal analysis, we demonstrate that SecureCollaRAG maintains robustness against attackers under non-IID data distributions.

## 2. 方法论概述

### 2.1 核心思想

- **拜占庭容错聚合**：将多个知识源视为分布式节点，假设恶意源占比 < 50%，通过多源信息的交叉验证识别异常文档，从而实现类似于拜占庭共识的防御。
- **动态可信度评分与图推理**：构建以文档为节点的同构验证图，利用动态图神经网络（GNN）学习文档的可信度，结合源可靠性的历史演化信息，过滤投毒内容。

### 2.2 关键技术细节

1. **分布式查询与检索**：用户查询经 LLM 分解后，分发至多个独立知识源，每个源返回 top-k 相关文档，形成聚合文档集合 \( D^{(t)} \)。

   - **节点**：每个文档对应一个图节点，提取12维特征（文档内容特征、图结构特征、交叉交互特征）。
   - **边**：基于文档间的复合相似度（语义相似度与类别相似度的加权融合）建立边，低于阈值则不连边。
   - **源可靠性感知的动态调制**：维护每个知识源的可靠性分数 \( \varrho_j^{(t)} \)，通过门控机制融合当前与历史可靠性，动态调节文档节点间的边生成，使图结构随信任信号实时演变。
3. **图神经网络可信度评分**：
   - 将节点特征与调制后的源可靠性拼接，经特征编码器、双层图注意力网络（含残差连接）提取隐藏表示。
   - 通过聚类模块计算节点与可学习原型的注意力分布，捕获全局结构模式。
   - 双通道分类器结合局部与全局特征，以 Sigmoid 输出文档可信度 \( C(d) \in [0,1] \)。
   - 训练损失为分类损失、拓扑感知损失（簇内方差正则 + 簇间对比）与门参数稀疏正则的加权组合，权重采用余弦退火调度。
4. **常识惩罚后处理**：对处于不确定区间 \([\tau_{\text{low}}, \tau_{\text{high}}]\) 的文档，调用独立常识 LLM 进行合理性判断，生成惩罚分数 \( P_c(d) \)，将该分数重新注入 GNN 二次计算可信度，最终低于阈值 \( \theta \) 的文档被丢弃。
5. **源可靠性更新**：采用指数滑动平均，根据留存文档的平均可信度更新源可靠性，实现长期的恶意源检测与隔离。
